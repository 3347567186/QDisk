## 3. 第四轮改动

### 3.1 卸载真正可用（核心修复）

- 根因：引擎 `_engine_apps_uninstall` 用 `Popen(cmd, shell=False)` 执行「带参数的完整命令行」，等于把整串当 exe 路径，几乎所有卸载按钮都点不动。
- 修复：改为 `shell=True` 的分离进程；遇到 `WinError 740`（卸载器要求管理员）自动走 `ShellExecuteW("runas")` 弹 UAC。
- 新增命令：`apps.registry`（查看注册表条目）、`apps.delete_entry`（只删注册表项）、`apps.force_remove`（删安装目录 + 注册表项，带系统目录安全闸）；`apps.uninstall` 支持 `mode=auto|interactive|quiet`。
- 实测：腾讯移动应用引擎 → 右键「卸载」→ 卸载器正常启动并完成卸载（「卸载已完成」）。

### 3.2 卸载页右键菜单（对齐 Geek Uninstaller）

卸载 / 强制删除（目录+注册表）/ 删除条目（只删注册表）/ 注册表条目… / 安装文件夹 / 程序网站 / 扫描残留 / 通过谷歌搜索 / 复制名称 / 复制版本。
注册表条目用弹窗表格展示全部值（名称/类型/值）。

### 3.3 管理员提权

- 提权按钮改为醒目的橙色条（`.admin-strip`，浅色 #fff7ed 底 + #fdba74 边 + #c2410c 按钮），不再与背景融合。
- `run_as_admin` 重写：先停引擎 → `Start-Process -Verb RunAs --elevated` → 旧实例退出；提权实例跳过单实例转发，避免 0x800700AA。

### 3.4 「查看」类功能折叠进页面

- 卸载页：分段按钮「全部 / 可卸载 / 无卸载器」+ 排序下拉（名称 / 大小 / 发行商）+ 刷新按钮（语言切换仍留在设置页）。
- 其它页统一顶栏动作按钮，不再有下拉「查看」菜单。

### 3.5 四项功能建议

1. **大文件排行**（新页「空间工具」）：选目录 → 列出最大 50 个文件，右键定位/复制，双击打开所在文件夹。
2. **空文件夹清理**（同页）：扫描空目录 → 勾选 → 二次确认删除（只删空目录）。
3. **托盘快捷菜单**：打开主界面 / 整理下载文件夹 / 打开数据目录 / 打开日志目录 / 退出。
4. **操作历史时间线**：日志页底部显示最近 20 次整理（时间、文件夹、移动文件数、新建目录数）。

## 8. 2026-11-15 17:55 第五轮：分类、卸载链路与代码收口

**卸载**
- 根因修复：卸载命令是「带参数的整串」，旧实现用 `shell=False` 把整串当 exe 路径，所以点了没反应；现改为 `shlex` 解析成 argv 后 `shell=False` 启动，参数不经过 shell（顺带去掉了注入面）。
- 需要提权的安装器（WinError 740）自动走 ShellExecute 的 `runas` 弹 UAC。
- 实测：腾讯移动应用引擎的卸载器成功拉起并完成卸载。

**卸载页分类**
- 新增「全部 / 桌面App / 商店App」三个分类；商店应用用 `Get-AppxPackage` 枚举（仅当前用户、跳过框架包与系统不可卸载包），支持卸载。
- 右键菜单按 Geek Uninstaller 补齐：卸载、强制删除（目录+注册表）、删除条目（仅注册表）、查看注册表条目、安装文件夹、程序网站、扫描残留、通过谷歌搜索、复制名称/版本。

**提权按钮**

- 改用 `-EncodedCommand` 传 PowerShell 脚本，路径含引号/空格/中文都不会被解析坏。

**空间工具（新增页）**

- 空文件夹清理：扫描并勾选删除（只删空目录，删除前二次确认）。
