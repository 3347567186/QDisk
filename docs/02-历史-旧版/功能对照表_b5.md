# 整理助手 功能对照表（b5 原生版 0.1.0）

说明：WPF 客户端替代 Tkinter 界面，业务仍由 Python 引擎执行。状态分三档：
**已接**＝界面可用且端到端验证过；**引擎**＝界面调用引擎方法（引擎有测试）；**受限**＝受系统策略/权限限制，界面如实提示。

## 一、整理文件

| 功能 | 状态 | 说明 |
|---|---|---|
| 选择文件夹 / 浏览 | 已接 | 目录选择器 |
| 扫描预览（递归/内容识别/快捷方式/强制/按日期/重名策略） | 已接 | options 浮层持久化 |
| 排除后缀 / 排除目录 | 已接 | 引擎 `exclude_exts/exclude_dirs`，实测 3 件 vs 7 件 |
| 跳过最近改动（分钟可调） | 已接 | 0–1440 分钟，`min_age_minutes` |
| 开始整理（二次确认） | 引擎 | 版本化记录、可撤销 |
| 撤销上次 | 引擎 | 只撤最近一份记录 |
| 导出 CSV | 已接 | 当前扫描结果，UTF-8 BOM |
| 批量删除 / 删除所在文件夹 | 已接 | 五道确认中的入口，回收站可还原 |
| 右键 6 项（打开/定位/复制路径/回收站/永久删/删目录） | 已接 | 行内 ContextMenu |
| 跳过明细 | 已接 | 显示被跳过文件与原因（含整目录被拒的情况） |
| 分类柱状图 | 已接 | 自测 `--chart-selftest` 通过 |
| 监控模式（30 秒，多目录，关窗继续） | 已接 | 监控选项与手动扫描共用排除规则 |
