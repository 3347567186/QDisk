# 整理助手 UI 重设计：设计规范（Windows 原生）

> 范围：全局设计语言、窗口外壳、组件、键盘、动效、无障碍。
> 配套文档：`UI重设计_逐页方案.md`（8 个页面 + 弹窗）、`UI重设计_框架迁移与功能映射.md`（技术方案、功能对照、待补充项）。
> 依据：`03_文档\说明.md`（784 行，现版本真实行为）+ `07_代码配置\tidy.py`（现实现）通读结论。
> 状态：设计稿。框架与承接方式按推荐值编写，标「待确认」的条目见第三份文档。

## 0 现状与目标

### 0.1 现状（事实）

| 维度 | 现状 |
|---|---|
| 技术栈 | Python 3.14 + Tkinter/t tk 手写界面；PyInstaller `--onedir` 打包（`整理助手.exe` 约 13.1 MB + `_internal\`）；托盘用 pystray；搜索索引用 SQLite；规则引擎内嵌 organize 3.3.0；迁移引擎在 `migrate_engine.py` |
| 页面 | 8 页：整理文件、清理截图、清理缓存、高级规则、卸载程序、搜索文件、设置、数据迁移 |
| 外壳 | 左侧竖排文字导航 + 右侧单页；顶部文件夹输入框；设置页 5 张默认收起的卡片 |
| 交互密度 | 大量复选框与按钮平铺；列表行高偏大；右键菜单承担了多数细粒度操作 |
| 系统集成 | 托盘、开机自启（3 档）、资源管理器右键菜单、3 个计划任务（自动扫描 / 清理截图 / 清理缓存）、数据目录指针 |

### 0.2 目标（来自任务书）

- 第一目标：快捷、简洁、高效率——「顺手、直观、少操作步骤」。
- 框架换成 Windows 原生；现有功能一个不删、不改语义。
- 系统原生优先：不造复杂自绘控件；层级靠字号字重；中性色为主；不用生硬边框；动效只表达层级。

### 0.3 本设计的三条硬约束

1. **不删功能**：现版本每个可点击项在方案里都有落点；删除类能力（回收站 / 永久删除 / 强制删除 / 批量删除所在文件夹 / 卸载）只换位置，不换含义。
2. **不弱化安全**：数据目录校验、缓存目录边界、卸载五道确认、删除拒绝清单，全部保留并原样呈现原因文案。
3. **可逐步替换**：界面按页迁移，旧 Tkinter 版本在迁移期可继续使用；数据格式（settings.json / 历史 JSON / 索引库 / 迁移任务）不动。

## 1 设计原则（由 apple-ui-designer 改写为 Windows 桌面）

| Apple 原则 | 本软件的 Windows 桌面落地 |
|---|---|
| Native over custom | 用 WPF 原生控件与系统窗口边框；不画自绘标题栏；用系统文件夹选择器、系统右键菜单、系统通知与任务栏行为 |
| Subtle over expressive | 无渐变、无霓虹、无阴影堆叠；只用 1px 分隔线与 8px 网格建立层次 |
| Calm / obvious | 每页只有 1 个主操作（实心强调色），其余为次级按钮或溢出菜单 |
| Neutral palette | 白 / 灰阶承载 95% 面积，强调色只出现在主操作、选中态、焦点框 |
| Hierarchy by size & weight | 3 级文字：页面标题 20 semibold、分组标题 14 semibold、正文 13 regular；不靠颜色分级 |
| No harsh borders | 分组用 16px 留白与分组标题；只有表格需要对齐时才用 1px `#E6E8EB` 横线 |
| Motion explains hierarchy | 页面切换 160 ms 淡入 + 8px 上移；展开 120 ms 高度动画；消息条 160 ms 滑入 |
| Touch targets | 桌面鼠标目标：按钮高 32px、行高 32px、勾选列 32px；触屏模式（待确认）再放大到 40px |
| Sheets → dialogs | iOS 底部 sheet 改写为居中模态窗口（WPF `Window`），宽度 420px，Esc 取消、主按钮默认焦点 |

### 1.1 工具型软件的四条效率准则

1. **一屏完成一件事**：每页一个主任务，主按钮固定在页面右上；不用来回切页。
2. **键盘可达**：所有高频动作有快捷键；列表全键盘操作；`Ctrl+K` 命令面板覆盖 90% 的跳转。
3. **状态可见**：长任务在底部状态栏显示进度与可取消；结果在页面内提示，不弹阻塞框。
4. **危险操作可识别**：破坏性按钮永远是红色描边而非实心红；确认框里明确写出「将删除 N 个文件 / 会删除注册表项」。

### 1.2 文案与视觉纪律

- 文案精简：按钮用「动词 + 名词」（扫描预览 / 开始整理 / 重建索引），状态用短句（正在扫描 / 已保存 / 需要管理员）；句末不加句号，少用感叹号、括号与引号嵌套。
- 不使用 emoji；图标一律取系统 `Segoe Fluent Icons` 或开源图标集（Lucide/Tabler 线稿，16/20/24 三档），同一页面不混用两套风格。
- 颜色默认白（主）+ 黑/灰（文字与线），红色只用于错误与删除，绿色只用于安全级与成功，橙色只用于谨慎级与「加载较慢」。
- 一屏强调色面积 ≤5%；不使用装饰性渐变、霓虹、投影堆叠。
- 每个元素必须可实现「出现 / 过渡 / 消失」三态；无过渡的硬切换视为缺陷（详见 [`UI重设计_加载占位与反馈规范.md`](UI重设计_加载占位与反馈规范.md)）。
- 交互细节必备：按钮悬停轻微放大（1.02）、按下回弹（0.98）、悬停/按下有背景或描边变化；可点区域有 `Hand` 光标；焦点框可见。

## 2 设计令牌

### 2.1 字体（Windows 系统字体，不嵌字体文件）

| 令牌 | 字体 | 字号 | 字重 | 用途 |
|---|---|---|---|---|
| T1 | Segoe UI Variable Display / Segoe UI | 20 | SemiBold (600) | 页面标题 |
| T2 | Segoe UI Variable Text / Segoe UI | 14 | SemiBold | 分组标题、对话框标题 |
| T3 | 同上 | 13 | Regular | 正文、按钮、列表主列 |
| T4 | 同上 | 12 | Regular | 次要说明、列头、状态栏 |
| T5 | 同上 | 11 | Regular | 路径、时间戳、计数、提示条 |
| T6 | Cascadia Mono / Consolas | 13 | Regular | 文件路径（等宽）、YAML 编辑器、日志 |

规则：同一区域最多同时出现两级字重（Regular + SemiBold）；不用 Italic 表强调；数字统一用比例数字；路径与命令等宽显示，便于核对。

### 2.2 间距 / 尺寸

| 令牌 | 值 | 用途 |
|---|---|---|
| S1 | 4 px | 图标与文字、行内元素 |
| S2 | 8 px | 控件内边距、列表行上下 |
| S3 | 12 px | 同组控件间距 |
| S4 | 16 px | 分区间距、卡片内边距 |
| S5 | 24 px | 页面左右留白、区块之间 |
| S6 | 32 px | 页面顶部留白 |
| 行高 | 32 px（列表 / 表格）、36 px（分组头）、28 px（状态栏） | — |
| 控件高 | 32 px 按钮与输入框；24 px 勾选框命中区 | — |
| 圆角 | 4 px（输入框 / 按钮）、6 px（对话框 / 浮层） | — |

栅格：8 px 基线。窗口最小 960×600，默认 1200×760；左栏 224 px，折叠 48 px。

### 2.3 颜色（浅色；深色随系统，待确认）

| 名称 | 值 | 用途 |
|---|---|---|
| Surface | `#FFFFFF` | 内容区背景 |
| SurfaceAlt | `#F7F8FA` | 左栏、状态栏、表头 |
| SurfaceHover | `#F0F2F5` | 行悬停 |
| SurfaceSelected | `#E8F1FB` | 行选中（配合系统强调色 12% 透明度亦可） |
| Line | `#E6E8EB` | 表格横线、输入框描边 |
| TextPrimary | `#1A1A1A` | 正文 |
| TextSecondary | `#5F6368` | 说明、列头 |
| TextTertiary | `#8A9099` | 计数、占位符 |
| Accent | 系统强调色（默认 `#0067C0`） | 主按钮、选中、焦点 |
| AccentHover | 强调色 90% | 主按钮悬停 |
| Success | `#107C10` | 「安全」级别、成功提示 |
| Warning | `#9D5D00` | 「谨慎」级别、黄色提示条 |
| Danger | `#C42B1C` | 破坏性按钮描边与文案、「高级」级别 |
| FocusRing | 强调色 2 px 外框 + 1 px 内白 | 键盘焦点，必须可见 |

配色纪律：一屏内强调色面积不超过 5%；绿色/橙色/红色只用于「级别」和「危险」，不做装饰。

### 2.4 图标

系统 `Segoe Fluent Icons`（Windows 10 1809+ 有；Windows 11 完整）。统一 16 px（列表/按钮）、20 px（左栏）、24 px（空状态）。不引入图标字体以外的素材包；若缺字形用 1 个语义近似的字符，不画 SVG。

### 2.5 动效

**三态原则**：每个会变化的元素都必须有「出现 / 过渡 / 消失」三段动画，缺任一段视为实现缺陷；系统关闭动画时全部降级为纯淡入淡出（不位移）。加载类组件的完整规格（Page Loader / Skeleton / Shimmer / Spinner / Progress / Circular / Button Loader、300 ms 防闪烁、8 s 出口）见 [`UI重设计_加载占位与反馈规范.md`](UI重设计_加载占位与反馈规范.md)。

| 场景 | 时长 / 缓动 |
|---|---|
| 页面切换 | 160 ms，`cubic-bezier(0.2,0,0,1)`，新页透明度 0→1 + 8 px 上移 |
| 展开 / 收起分组 | 120 ms 高度 + 透明度，箭头 90° 旋转 120 ms |
| 消息条（InfoBar） | 160 ms 滑入，3 s 后自动收起（危险提示不自动收） |
| 对话框 | 120 ms 透明度 0→1、scale 0.98→1 |
| 悬停 / 按下 | 悬停 80 ms 背景色变化 + 轻微放大（scale 1.0→1.02，仅按钮）；按下 60 ms 缩到 0.98，松手 80 ms 回弹（仅按钮；列表行不缩放） |
| 进度条 | 不确定态用系统 marquee；确定态 200 ms 插值跟随；100% 后 180 ms 变绿并保持 1 s |
| 骨架 → 内容 | 骨架 160 ms 淡出，内容 160 ms 淡入 + 4 px 上移，同位置替换 |
| 骨架扫光（Shimmer） | 1.2 s/轮循环，`#F2F3F5 → #FFFFFF 40% → #F2F3F5`，窗口失焦暂停 |
| 按钮加载态 | 立即进入，文案与 14 px Spinner 120 ms 淡入；成功 200 ms 换回 + 1 s 勾；失败同尺寸变「重试」 |
| 焦点 | 2 px 强调色外框，120 ms 淡入；不用虚线 |

系统关闭动画（`SystemParameters.ClientAreaAnimation = false`）时：全部降级为无位移的即时切换。

## 3 窗口外壳

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 系统标题栏（原生 caption：最小化 / 最大化 / 关闭，支持 Win11 贴靠布局）        │
├──────────────┬───────────────────────────────────────────────────────────────┤
│ 整理助手      │ 整理文件                                    [选项] [扫描预览] │  ← 命令栏 56px
│ ───────────  │ ───────────────────────────────────────────────────────────── │
│ ▸ 整理文件    │                                                               │
│   清理截图    │                        页面内容区                             │
│   清理缓存    │                  （页面内边距 24px）                          │
│   高级规则    │                                                               │
│   卸载程序    │                                                               │
│   搜索文件    │                                                               │
│   设置        │                                                               │
│   数据迁移    │                                                               │
│              │                                                               │
│ [折叠 48px]   │                                                               │
├──────────────┴───────────────────────────────────────────────────────────────┤
│ 就绪 · 已选 3 个 · 4.2 GB            [━━━━━━ 62% 正在扫描…]  [取消]  管理员：否 │  ← 状态栏 28px
└──────────────────────────────────────────────────────────────────────────────┘
```

- **标题栏**：用系统原生 caption（`WindowStyle=SingleBorderWindow`），不自绘。标题固定「整理助手」，副标题不放版本号（版本号进「关于」）。
- **左栏**：`ListBox` 自定义 ItemTemplate（图标 20 + 文字 13）。选中态左侧 3px 强调色竖条 + `SurfaceSelected` 背景；无分组线。折叠按钮在左栏底部，折叠后只留图标 + Tooltip（「整理文件 Ctrl+1」）。
- **命令栏**：左侧页面标题（T1）；右侧主操作（实心强调色按钮）+ 次级动作（描边按钮）+ 溢出菜单（`…`，只放低频动作）。
- **内容区**：`Grid` 三行——筛选/汇总条（40px，可选）→ 主列表/表单（`*`）→ 页脚说明（可选 24px）。
- **状态栏**：常驻。左：短状态（就绪 / 正在扫描 / 已保存到 …）；中：选择计数或当前任务；右：进度 + 取消按钮 + 管理员状态（点击可「以管理员身份重启」）。任何长任务必须出现在这里，不用模态进度条。
- **窗口尺寸记忆**：保存到 settings（`ui_window`），不再每次居中 1116×799。

### 3.1 导航与页面切换

- 8 个目的地固定顺序（与现版本一致，用户肌肉记忆不变）。
- 切换用 `ContentControl` + `DataTemplate`，160 ms 淡入；列表滚动位置在会话内保留。
- 每页首次加载才实例化（懒加载），冷启动只加载「整理文件」。
- 深链接：`整理助手.exe --page=cache` / `--path=<目录>`（右键菜单用），启动后直接定位。

## 4 组件规范

### 4.1 按钮

| 类型 | 视觉 | 用法 |
|---|---|---|
| Primary | 实心强调色，白字，高 32，圆角 4 | 每页唯一主操作（扫描预览 / 开始迁移 / 保存） |
| Secondary | 白底 + 1px `Line`，文字 `TextPrimary` | 次级动作（浏览、撤销上次、导出） |
| Danger | 白底 + 1px `Danger`，文字 `Danger` | 破坏性动作（永久删除、强制卸载） |
| Text | 无边框，悬停出现 `SurfaceHover` | 行内动作（打开位置、复制路径） |
| SplitButton | Primary + 右侧箭头 | 「开始整理 ▾」：整理 / 整理并跳过预览确认 |

禁则：一屏不超过 1 个实心主按钮；不使用图标-only 按钮承载唯一入口（必须有 Tooltip + 快捷键）。

### 4.2 输入

- 文本框高 32，`Line` 描边，聚焦时 2px 强调色描边；错误时描边 `Danger` + 输入框下方 12px 红字原因。
- 路径输入框：右侧「浏览…」按钮打开系统 `OpenFolderDialog`；支持拖放文件夹到窗口（Drop 高亮整条输入框）。
- 搜索框：左侧放大镜图标，右侧 `Esc` 清空提示；输入 300 ms 防抖。
- 下拉框用系统 `ComboBox`，不用自定义 popup。

### 4.3 列表与表格

- 统一 `ListView` + `GridView`（需要排序时用 `DataGrid`，但禁止单元格编辑态）。
- 开启 UI 虚拟化（`VirtualizingPanel.IsVirtualizing=true`、`VirtualizationMode=Recycling`），10 万行滚动不卡。
- 行高 32；悬停 `SurfaceHover`；选中 `SurfaceSelected`；键盘焦点整行外框。
- 列头 12px `TextSecondary`，可点击排序的列显示箭头；不可排序列不显示箭头。
- 分组行（清理缓存 / 整理预览的分类）：高 36，14 semibold，左侧 chevron，整行可点展开。
- 勾选列固定宽 32，居中；表头放「全选」勾选框。

### 4.4 消息条（InfoBar）

替代现版本的 `messagebox.showwarning`（非阻塞场景）。高 40，圆角 4，四种语义：
信息（蓝）/ 成功（绿）/ 警告（黄）/ 错误（红）。包含图标 + 一句原因 + 可选动作按钮（「包含子文件夹并重扫」「重新指定数据目录」）。同一时刻最多 1 条，出现在内容区顶部，不遮挡命令栏。

### 4.5 对话框

- 居中于主窗口，宽 420（表单）/ 560（确认清单），无最大化。
- 结构：标题（T2）+ 正文（T3，可滚动区）+ 底部右对齐按钮（取消在左、主操作在右）。
- 破坏性确认：正文列出将删除的对象（目录/注册表项，最多 15 条 + 总数），主按钮显示动词 + 数量（「永久删除 12 个文件」）。
- 卸载确认仍保留「输入删除两个字」这道闸门（原样保留，只换成现代输入框样式）。
- 关闭行为询问框：回车 / Esc / 右上角 × 一律按「最小化到托盘」处理（沿用现行为，原因：误关成退出会中断任务）。

### 4.6 命令面板（Ctrl+K）

- 浮层 520×420，顶部输入框，下面按「跳转 / 当前页动作 / 最近路径」分组列出命令与快捷键。
- 支持模糊匹配中文与英文；回车执行；Esc 关闭。
- 首版命令集：8 个页面跳转、扫描当前路径、开始整理、撤销上次、导出 CSV、打开数据目录、切换主题（若启用深色）、关于。

### 4.7 托盘与系统集成（沿用现能力，换实现）

| 能力 | 现状 | 新实现 |
|---|---|---|
| 托盘图标与菜单 | pystray | WPF 用 `NotifyIcon`（WinForms 互操作）或 Hardcodet.NotifyIcon.Wpf；菜单项与原菜单一一对应 |
| 开机自启 3 档 | 计划任务 `整理助手_开机自启` | 保留同一任务名与参数，兼容旧版开关 |
| 右键菜单 | `HKCU\Software\Classes` 三处 | 原样保留（注册表路径与命令行参数 `--path` 不变） |
| 计划任务 3 个 | `整理助手_清理截图` / `整理助手_清理缓存` / 每日自动扫描 | 保留任务名与参数格式，避免用户已建任务失效 |

### 4.8 加载与占位组件（速查）

| 组件 | 何时用 | 尺寸 | 关键约束 |
|---|---|---|---|
| Page Loader | 首屏/整页、0.6~5 s | 内容区遮罩，环形 24 | 立即出现；完成后 200 ms 淡出；禁止提前交互 |
| Skeleton | 结构已知、数据未到 | 行高 32 / 分组 36 / 卡片实际高 | 延迟 120 ms；与真实布局 1:1；交叉淡入 |
| Skeleton + Shimmer | 骨架持续 >300 ms | 扫光带宽 30% | 1.2 s/轮；失焦暂停；内容到达立即停 |
| Spinner | ETA 未知的后台任务 | 24，圆环 2 px | 300 ms 延迟；「处理中 请勿关闭」；8 s 见取消/重试 |
| Progress Bar | 可量化任务 | 高 4 | 百分比 + 阶段；200 ms 插值；100% 变绿并给完成按钮 |
| Circular Progress | 紧凑位置 | 40（小 24） | 中心 11 px 数字；100% 变绿打勾；红色仅告警 |
| Button Loader | 按钮触发（保存/执行/开始） | 锁定按钮宽 | 立即进入；不换布局；8 s 出取消；失败变重试 |

详细时序、判定树、页面 × 加载态矩阵见 [`UI重设计_加载占位与反馈规范.md`](UI重设计_加载占位与反馈规范.md)。

### 4.9 交互细节（必须实现）

- 按钮：悬停 scale 1.02（80 ms）、按下 0.98（60 ms）、松手回弹（80 ms）；键盘 Space 按下同样反馈。
- 单选/勾选：悬停整行浅底，勾选 120 ms 打勾路径动画；禁止用浏览器默认样式。
- 可点区域：行内文字按钮至少 32×32 命中区；列表整行可点时不放独立小按钮。
- 光标：可操作处 `Hand`（命令面板、链接式按钮），其余保持箭头，输入框保持 I 形。
- 拖放：进入窗口时整条路径输入框描边变强调色 + 背景 `SurfaceHover`，离开复位。
- 焦点：Tab 顺序按视觉顺序；`Shift+Tab` 反向；焦点不可丢（加载完成回到触发元素）。
- 状态回执：任何保存/执行都在 300 ms 内给出可见回执（行尾「已保存」/按钮成功态/状态栏短消息），不依赖对话框。
- 禁止：emoji、装饰性渐变、霓虹阴影、非系统图标、无回执的静默操作。

## 6 状态与反馈

| 状态 | 表现 |
|---|---|
| 加载 | 列表区域骨架行（3 行灰条）+ 状态栏「正在扫描…」；超过 400 ms 才显示，避免闪烁 |
| 空 | 居中图标 24 + 一句说明 + 主操作按钮（如「选择文件夹」）；不画插画 |
| 部分失败 | 页面顶部黄色消息条：失败 N 项 ·「查看详情」打开日志面板 |
| 成功 | 状态栏绿色短消息 3 秒，例如「已整理 128 个文件」；关键操作同时写日志 |

| 长任务 | 状态栏进度 + 取消；取消后保留已完成部分并说明 |
| 离线 / 缺组件 | 页面内说明 + 安装指引（如 es.exe 缺失显示「使用本地索引」） |

## 7 无障碍与系统适配

- 200% DPI 下布局不重叠；所有尺寸用 DIP，禁用像素硬编码。
- 高对比度主题：不自定义颜色时跟随系统；自定义颜色在有 `SystemParameters.HighContrast` 时退回系统画刷。
- 屏幕阅读器：每个控件有 `AutomationProperties.Name`；列表行朗读「文件名 + 位置 + 大小」；进度用 `AutomationProperties.LiveSetting=Polite` 播报。
- 键盘可达：Tab 顺序 = 视觉顺序；焦点框 2px 强调色；不允许无焦点可到达的按钮。
- 动画尊重系统「显示动画」设置；关闭后无位移。

## 8 与现版本的差异清单（有意调整，逐条给出理由）

| 现版本 | 新方案 | 理由 |
|---|---|---|
| 设置页 5 张可折叠卡片默认收起 | 设置页改为单页分组（分组标题 + 行），默认全展开，页内滚动 | 折叠让用户二次点击；设置是低频页，滚动成本低于展开成本；与 Windows 设置习惯一致 |
| 设置需要点「保存设置」 | 非破坏性设置即时生效（行内「已保存」微提示）；数据目录变更仍走「先保存后问迁移」 | 少一步操作；数据目录涉及迁移，必须保留显式确认 |
| 顶部一排复选框（现版本主要收进「⚙ 选项」弹窗） | 选项仍收进「选项」浮层（Popup 贴命令栏右侧），按三组排列：扫描范围 / 分类行为 / 自动化 | 保留「默认界面干净」的现状优点，浮层比模态窗口更快 |
| 批量操作条常驻列表上方 | 勾选后浮出底部操作条（Overlay），Esc 或取消勾选后消失 | 不占常态空间，符合「信息密度服务效率」 |
| 表格三档删除按钮常驻 | 常驻仅「移到回收站」，永久/强制放进右键与 Shift+Delete | 危险动作降权，避免误触 |
| 列表行高偏大 | 32px 紧凑行高 | 同屏更多条目，减少滚动 |
| 黄色提示条用 messagebox | 用页面内 InfoBar | 不阻塞，可带回滚动作 |
| 清理缓存按平铺清单 | 按 6 组折叠 + 选中行显示「边界」说明 | 43 项平铺难扫；分组后仍是全部项 |
| 搜索页两个后端靠文字说明 | 搜索框内显示当前后端徽标（本地索引 / es.exe） | 用户随时知道为什么快或慢 |
| 数据迁移页控件平铺 | 左侧表单 + 右侧总览 + 底部进度的三栏布局 | 预演与执行同屏对比，减少来回切换 |

> 以上调整不改变任何功能语义；验收时逐条对照 `UI重设计_框架迁移与功能映射.md` 的功能映射表。
