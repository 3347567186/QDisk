# 规则：程序目录一律不动

这条规则是 2026-10-30 补上的，起因是两次真实事故。

## 事故一：程序目录被「合并」进另一个程序目录

`D:\App\123网盘\123pan\` 整个被搬进 `D:\App\百度网盘\`，原位置只剩一个空目录。
后果：开始菜单快捷方式、注册表中的卸载项全部指向不存在的路径，卸载不掉、更新不了。
同类受害者：`D:\各种拓展\`（里面有 BitComet、BoosterX、dism++）、`D:\ai软件\`、
`D:\Mineradio\`、`D:\Tool\VisualStudio\`、`D:\Tool\Codex++`、`D:\Tool\沙漏\` …

## 事故二：盘符根目录被当成缓存目录清空

设置里 `cache_custom_dirs` 曾填着 `C:\` 和 `D:\`。
2026-10-29 17:41:28 那一次清理删掉 **254845 个文件 / 43.24 GB**，
`D:\App`、`D:\Tool` 下一批软件只剩空壳：CapCut、bilibili、BandiZip、ATK HUB、
AweSun、向日葵、VisualStudio、阿里 keytool ……

## 判定：什么样的目录算「程序安装目录」

任一命中即算（`rules.json → app_dir_*`）：

| 依据 | 例子 |
|---|---|
| 第一层有卸载器 | `unins000.exe`、`uninstall.exe`、`uninst.exe` … |
| 第一层有卸载目录 | `uninstall\`、`卸载\`（残壳也认） |
| 有 Electron / 引擎特征文件 | `app.asar`、`icudtl.dat`、`chrome_100_percent.pak`、`unityplayer.dll` |
| 有可执行文件 + ≥3 个运行时文件 | 1 个 `.exe` + 3 个 `.dll/.pak/.dat/.bin` |

**软件总目录**（`app_container_min`，默认 2）：第一层里有 ≥2 个程序目录，
判定为「一堆软件的总目录」——`D:\各种拓展` 就是这样一整片消失的。

## 落地位置

| 功能 | 位置 | 行为 |
|---|---|---|
| 整理 | `tidy.py check_target()` / `scan()` | 选中程序目录或软件总目录直接拒绝，并说明原因；`force` 也不放行 |
| 整理（递归） | `Plan.skip_subtree` | 子树里遇到程序目录，整棵不碰 |
| 缓存清理（准入） | `tidy.py check_cache_custom_dir()` | 盘符根目录、程序目录、程序目录的父目录、层级 >6 层，一律不许加为自定义缓存目录 |
| 缓存清理（执行） | `clean_cache_paths(rules=…)` | 盘符根目录直接拒绝；程序目录整棵跳过；`.exe/.dll/.sys/.asar/.db/.reg` 等 28 类文件不删 |
| 计划任务 | `run_clean_cache()` | 同上，并把「拒绝的自定义目录」「跳过的程序项」写进 `数据\缓存清理.log` |
| 迁移 | `migrate_engine.py preflight()` | 来源是程序目录 → 报错拒搬（`allow_root` 也不放行）；目标是程序目录 → 拒绝写入；合并进程序目录 → 拒绝；来源是软件总目录 → 警告快捷方式会失效 |

## 已知不做的事

- 不判断「这个程序该不该装」——只保证已经装好的目录不被搬、不被清。
- 不追查历史：被清空的历史目录不会自动恢复（回收站里也没有）。

## 当前设置

不是程序目录的父目录、层级 ≤6、路径存在。
