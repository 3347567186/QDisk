- 通信层 `Services/EngineClient.cs`：spawn `整理助手引擎.exe --engine`（或 `py tidy.py --engine`），UTF-8 单行 JSON；请求 `{"id","method","params"}`，响应 `{"id","ok","result|error"}`；`params` 键（不是 args）；10 分钟默认超时、错误写日志不抛 UI、进程退出时 fail 全部 pending 并触发 `EngineStateChanged(false)`。

## 已知差异与限制

1. `skip_shortcuts` 是引擎既有死参数（`.lnk/.url` 由 `rules.json` 的 `never_move_exts` 无条件跳过），客户端保留选项并回显 `applied`，但不会改变行为——需产品确认是否改规则语义。
2. 「强制整理」可绕过软件目录/代码工程/源码目录判定，但 `looks_like_app_dir` 容器仍硬挡（既有安全行为）。
3. 计划任务创建（截图/缓存自动清理）在本会话被权限/安全软件拒绝；界面显示具体错误。
4. 右键菜单写入 `HKCU\Software\Classes` 在本会话子进程被沙箱拒绝（宿主 reg add 可写）；真实 Explorer 启动的进程不受此限。
5. 清理截图/缓存的自定义目录现可在设置页增删（写 `shot_dirs` / `cache_custom_dirs`），但引擎侧「自定义缓存目录」的既有准入校验（盘符根/程序目录/层级）在设置页未做前置提示，失败会显示引擎错误。
6. MSI 为 perMachine，安装/卸载需要管理员；自签证书未受信，首次运行可能提示「未知发布者」。
