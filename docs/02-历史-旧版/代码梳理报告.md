## 0. 已修复：启动时多出一个终端窗口

**现象**：双击快捷方式后，额外弹出一个标题为 `TidyAssistant` 的终端窗口，关掉它可能连带结束进程。

**原因**：`src-tauri\src\main.rs` 缺少 Windows 子系统声明，Rust 默认按 **控制台程序** 链接，于是系统为进程创建一个控制台窗口。
PE 头验证：修复前 `Subsystem = 3 (CONSOLE)`。这是产物属性，不是代码逻辑，所以功能测试时没暴露。

**改法**（一行，文件第 1 行）：

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]
```

**验证**：重新构建后读 PE 头 `Subsystem = 2 (WINDOWS_GUI)`；启动实测无终端窗口，进程只剩 `tidy-assistant`（pid 21208），`MainWindowTitle=整理助手`。

**注意**：修复后 `--engine` 之类需要控制台输出的调试场景不受影响（`tidy.py` 是独立 Python 进程，自己的 console 由 `CREATE_NO_WINDOW` 控制）。
