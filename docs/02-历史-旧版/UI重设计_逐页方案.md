# 整理助手 UI 重设计：逐页方案

> 配套：`UI重设计_设计规范.md`（令牌、外壳、组件、键盘）、`UI重设计_框架迁移与功能映射.md`（技术方案与功能对照）。
> 每页统一给 5 项：设计意图 / 布局结构 / 字体字号字重 / 交互与动效 / 为什么符合工具型高效与 Windows 原生；另附「功能落点」确保不漏。
> 线框中的尺寸单位：px（WPF 中为 DIP）。左栏 224（折叠 48），命令栏 56，内容区左右留白 24，状态栏 28。

## 页 1 · 整理文件（主页面）

### 1.1 设计意图

主页面只回答一个问题：「这个文件夹，扫一下、看一眼、整理掉」。所有开关默认收进「选项」浮层，主路径保持 3 步以内：选文件夹 → 扫描预览 → 开始整理。预览结果用可折叠分组 + 勾选列承载批量操作，危险动作降权到右键与快捷键。

### 1.2 布局结构

```
┌ 命令栏 56 ────────────────────────────────────────────────────────────────┐
│ 整理文件                                     [选项 ▾]  [扫描预览 Ctrl+Enter] │
├ 筛选/汇总条 40 ───────────────────────────────────────────────────────────┤
│ [D:\下载                    ▾] [浏览…]        共 128 个文件 · 4.2 GB · 12 类  │
├ 主列表 * ──────────────────────────────────────────────────────────────────┤
│ ▾ 03_文档                            03_文档\        86 个    1.8 GB   [✓] │
│    报告-2026Q1.docx                  D:\下载\        —       2.1 MB   [✓] │
│    合同-甲方.pdf                     D:\下载\        —       840 KB   [ ] │
│ ▸ 05_图片                            05_图片\        42 个    2.4 GB   [✓] │
│ ▸ 15_其他                            15_其他\        0 个     0 B      [ ] │
├ 底部浮出操作条（有勾选时）────────────────────────────────────────────────┤
│ 已选 37 个 · 1.9 GB        [移到回收站] [永久删除] [删除所在文件夹]   [Esc] │
└───────────────────────────────────────────────────────────────────────────┘
状态栏：就绪 · 12 类 / 128 个文件 · 4.2 GB                      管理员：否
```

| 区域 | 规格 |
|---|---|
| 路径行 | `TextBox` 高 32（等宽 T6 显示路径）+「浏览…」；支持拖放文件夹；地址栏式历史下拉（最近 5 个） |
| 汇总条 | 左：路径与来源；右：`共 N 个文件 · 总大小 · N 类`（T5 灰） |
| 主列表 | 列：`分类/文件`（`*`，可展开树）、`选`（32 固定）、`位置`（260）、`文件数`（72，右对齐）、`大小`（88，右对齐） |
| 分组行 | 36 高，chevron 16 + 分类名（T2 14 semibold）+ 计数（T5）；整行点击展开；右侧勾选框 = 整组全选/半选 |
| 文件行 | 32 高；文件名 T3 13；位置 T5 11 灰、超出省略并 Tooltip 全文 |
| 浮出操作条 | 高 48，居中悬浮于列表底部上方 12；半透明 `Surface`，圆角 6；无勾选时隐藏 |
| 顶部黄色提示条 | 扫描结果明显偏少时出现（沿用现逻辑）：「当前只扫到顶层 1 个文件，子目录里还有约 64 个未扫」+「包含子文件夹并重扫」 |
| 日志 | 不再常驻页面（现版本右下角日志框占空间）；改为状态栏短消息 + 「查看日志」打开侧抽屉（320 宽，可关） |

「选项」浮层（`Popup`，宽 320，贴命令栏右下），三组，全部沿用现语义：

| 组 | 控件 |
|---|---|
| 扫描范围 | `包含子文件夹（递归 N 层）` 勾选 + 层级 `NumberBox`（默认 3）；`跳过 10 分钟内改动过的`；`跳过快捷方式` |
| 分类行为 | `按内容识别`；`强制整理`（危险说明：绕过程序/工程/源码拦截）；`按日期分目录（年/月）`；`重名策略` ComboBox（自动改名 / 跳过 / 备份旧文件）；`整理列`（就地分类 / 按日期） |
| 自动化 | `监控模式`（每 30 秒检查）；`每天自动扫描 HH:MM` + `创建任务` / `删除任务` + 状态「已设置 / 未设置」 |

命令栏「更多…」仅 3 项：`撤销上次整理`、`导出预览 CSV`、`打开数据目录`。

### 1.3 字体 / 字号 / 字重

| 元素 | 令牌 |
|---|---|
| 页面标题「整理文件」 | T1 20 SemiBold |
| 分组行分类名 | T2 14 SemiBold；计数 T5 11 Regular |
| 文件行 | T3 13 Regular；路径 T5 11 Regular（等宽路径输入框 T6） |
| 列头 | T4 12 Regular，`TextSecondary` |
| 浮出操作条计数 | T4 12 |
| 状态栏 | T5 11 Regular |

### 1.4 交互与动效

- 点「扫描预览」→ 主按钮进入禁用态并显示「扫描中…」+ 状态栏不确定进度；扫描结果一次填入（超过 400 个分组不做逐行动画，整块淡入 160 ms）。
- 展开/收起分组：120 ms 高度动画，chevron 旋转；键盘 `←/→` 同效。
- 勾选：分组行与文件行联动；`半选` 用短横线图标；勾选变化即时更新浮出条计数，不做动画。
- 双击：分组行展开/收起；文件行打开预览（图片看原图、文本前 4 KB、其他显示属性），预览用非模态侧抽屉（480 宽），Esc 关闭。
- 右键菜单（原生 `ContextMenu`）：分组行 = 预览 / 展开全部 / 移到回收站 / 永久删除 / 删除所在文件夹 / 复制路径；文件行 = 预览 / 打开文件 / 打开所在位置 / 复制路径 / 移到回收站 / 永久删除 / 强制删除。
- 删除确认：一个对话框列出 N 个文件与总大小；永久删除与强制删除在对话框中再显示一行红色说明「不可撤销」；批量删除所在文件夹额外列出目录清单（沿用现有统计与硬性拒绝条件，拒绝原因用消息条显示）。
- 「开始整理」= SplitButton：「整理」（默认，弹整理结果摘要）与「整理并跳过确认」（记住选择后不再弹）。
- 扫描中再次点扫描 → 变为「取消」。
- 页面切换离开时保留扫描结果与勾选状态（会话内）。

### 1.5 为什么符合工具型高效 + Windows 原生

- 主路径 3 步、主按钮唯一且可用 `Ctrl+Enter`；选项只占 1 次点击，不污染主界面——与现版本「顶部只有输入框 + 一行动作」的设计意图一致，但把选项浮层做得可键盘操作。
- 列表紧凑 32px 行高 + 虚拟化，一屏比现在多看 4~6 行；勾选后用浮出条批量操作，符合资源管理器/照片应用的 Windows 习惯。
- 右键菜单、系统文件夹选择器、拖放、状态栏进度都是 Windows 用户既有预期，不引入新交互范式。

### 1.6 功能落点（不漏）

文件夹选择/输入、最近路径、扫描预览（含递归、跳过规则、强制整理、按内容识别）、分类树展开/折叠（全部展开/折叠并入分组行与 `Ctrl+Shift+E`）、勾选（单文件/整组/全选/反选/清空）、批量移到回收站、批量永久删除、批量删除所在文件夹、单文件三档删除、预览、打开文件/打开位置、复制路径、撤销上次整理、导出预览 CSV、重名策略、按日期分目录、递归深度、监控模式、每日自动扫描计划任务、日志查看、扫描偏少提示条。

## 页 2 · 清理截图

### 2.1 设计意图

清截图是「定期扫一遍、勾几张、删掉」的低频维护任务。页面第一屏直接给「扫描」和「所有截图」两个动作，参数与目录管理降到第二行；删除永远可回收到回收站。

### 2.2 布局结构

```
┌ 命令栏 ───────────────────────────────────────────────────────────────────┐
│ 清理截图                                        [管理目录…]  [扫描 F5]     │
├ 参数行 40 ────────────────────────────────────────────────────────────────┤
│ 目录 4 个（3 个存在） · 保留最近 [7] 天 · 忽略小于 [0] KB · ☑ 移入回收站   │
├ 主列表 * ──────────────────────────────────────────────────────────────────┤
│ [✓] 屏幕截图 2026-11-01.png   D:\图片\Screenshots   1.2 MB   11-01 10:22  │
│ [ ] Screenshot_2026-11-02.png D:\下载               840 KB   11-02 09:10  │
├ 底部浮出条（有勾选时）───────────────────────────────────────────────────┤
│ 已选 12 张 · 28.4 MB                       [清理选中…] [全部清理…]        │
└───────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 目录概况 | 「N 个目录（M 个存在）」可点击 = 打开「管理目录」对话框（沿用现四列：启用/目录/状态/概览 + 添加/恢复默认/移除选中/关闭） |
| 参数 | 保留天数 `NumberBox`（默认 7）；忽略小于 KB `NumberBox`（默认 0）；`移入回收站` 勾选（默认开） |
| 列表列 | `选` 32、`文件名` `*`、`所在目录` 300、`大小` 88 右对齐、`修改时间` 120 |
| 浮出条 | `清理选中…`（危险描边）、`全部清理…`（危险描边）；执行前列出数量与总大小 |
| 自动清理 | 页面底部一行：`每天自动清理 [23:30] [创建任务]` + 状态「每天 23:30 / 未设置」+`删除任务` |

### 2.3 字体 / 字号 / 字重

页面标题 T1；参数行 T4 12（数值控件 T3 13）；列表文件名 T3，目录/时间 T5 灰；计数 T4；状态栏 T5。

### 2.4 交互与动效

- 扫描：状态栏进度 + 可取消；结果整块淡入。
- 勾选：双击整行切换勾选（沿用现行为）；选中行背景 `SurfaceSelected` + 文字 Medium（不用加粗到影响列宽）。
- 右键菜单：预览 / 打开位置 / 勾选·取消勾选 / 只清理这一张（确认）/ 删除这一张（回收站，不确认）/ 全选 / 反选。
- 清理：确认对话框列出 N 张与总大小，主按钮「清理 12 张」；完成后消息条「已清理 12 张，回收站可还原」。
- 管理目录对话框改动即时保存并回写页面概况（沿用现行为）。

### 2.5 为什么符合工具型高效 + Windows 原生

- 把「保留天数 / 忽略大小 / 回收站」三个最常改的参数放第一行，改完直接扫描，不用进设置。
- 列表即操作面：双击勾选、右键单张清理，与资源管理器习惯一致。
- 计划任务状态原位显示，避免「以为设了其实没设」。

### 2.6 功能落点（不漏）

按文件名识别的 15 种前缀、只处理图片/录屏扩展名、目录管理（启用/存在状态/概览/添加/恢复默认/移除）、保留天数、最小 KB、移入回收站（可还原）、扫描、清理选中、全部清理、单张清理（确认/不确认两档）、右键菜单六项、双击勾选、全选/反选/清空、已选计数、每天自动清理计划任务（创建/删除/状态）、无控制台执行。

## 页 3 · 清理缓存

### 3.1 设计意图

把 43 项缓存从「一长条平铺清单」变成「按组折叠 + 行内级别 + 选中看边界」。默认只推荐「安全」级；「谨慎/高级」必须手动勾，页面用级别色标清楚表达风险。

### 3.2 布局结构

```
┌ 命令栏 ───────────────────────────────────────────────────────────────────┐
│ 清理缓存                              [添加目录…] [扫描缓存 F5] [清理推荐 ▾]│
├ 汇总条 40 ────────────────────────────────────────────────────────────────┤
│ 命中 24 项 · 可释放 3.8 GB · 已选 8 项（1.2 GB）        [全选安全级]       │
├ 主列表 *（分组树）────────────────────────────────────────────────────────┤
│ ▾ 系统                10 项 · 1.9 GB                                     │
│   [✓] 用户临时文件        安全   1.2 GB   24,318 个文件                    │
│   [ ] 回收站              谨慎   820 MB   1,204 个文件                     │
│ ▸ 浏览器              4 项 · 640 MB                                      │
│ ▸ 开发                9 项 · 980 MB                                      │
│ ▸ 应用 / 商店应用 / 桌面应用                                             │
├ 边界说明 48 ──────────────────────────────────────────────────────────────┤
│ 用户临时文件：删 %TEMP% 下可删除的文件，跳过被占用项；不动系统目录与个人文件。│
└───────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 级别 | 文本徽标：安全（绿）/ 谨慎（橙）/ 高级（红），字号 T5 11；不做彩色底块 |
| 列 | `选` 32、`名称` `*`、`级别` 64、`大小` 88 右、`文件数` 88 右 |
| 分组 | 6 组：系统 / 浏览器 / 开发 / 应用 / 商店应用 / 桌面应用；分组头显示项数与合计 |
| 边界说明 | 选中任一行时在底部固定 48px 区域显示该行「删什么、不动什么」（现版本就在表格下方灰底文字，位置一致） |
| 清理推荐 | SplitButton：「只清安全级」（默认）/「清理安全级并重扫」 |
| 自定义目录 | 「添加目录…」打开系统文件夹选择器，走与现 「自定义缓存目录」同一套准入校验（盘符根/程序目录/层深>6 拒绝，原因用错误对话框呈现） |
| 自动清理 | 底部：`每天自动清理 [23:40] [创建任务]` + 状态 + `删除任务`（只清安全级 + 自定义目录，写 `数据\缓存清理.log`） |
| 右键菜单 | 打开位置 / 复制路径 / 只清理这一项 / 从列表移除 |

### 3.3 字体 / 字号 / 字重

页面标题 T1；分组名 T2 14 SemiBold + 计数 T5；行名 T3 13；级别/大小/文件数 T4 12；边界说明 T4 12 `TextSecondary`；状态栏 T5。

### 3.4 交互与动效

- 扫描：状态栏进度（现版本是分项扫描，仍按项更新进度）；结果分组淡入。
- 展开组：120 ms 高度动画；默认全展开（43 项，分组后一屏可见 2~3 组，滚动可接受）。
- 勾选：安全级默认不勾（现版本「清理推荐」才自动全选安全级）；「全选安全级」按钮一键勾。
- 清理：确认框列出项名与总大小 + 一句「只删缓存内容，不删目录本身；被占用文件自动跳过」。
- 完成：消息条「已清理 8 项，释放 1.2 GB」+ 自动重扫（沿用现行为）。
- 不可用项（需管理员）：行右侧显示「需管理员」，点击状态栏管理员入口可重启提权。

### 3.5 为什么符合工具型高效 + Windows 原生

- 43 项分组折叠后，扫描结果一眼看清「哪类占得多」；级别用最小视觉成本表达风险。
- 「清理推荐」保留为唯一实心主操作，危险项永不默认选中，符合 Windows 存储感知的保守默认。
- 边界说明固定在原地，不用悬停猜——符合「工具要讲清楚它动了什么」的效率诉求。

### 3.6 功能落点（不漏）

内置 43 项清单（系统/浏览器/开发/应用/商店应用/桌面应用）、三级颜色与含义、清理推荐（仅安全级）、清理选中、添加自定义目录（含准入校验）、右键四项、每天自动清理（只清安全级+自定义、写日志）、管理员项失败记录、只清内容不删目录、跳过占用文件、删后重扫、危险目录黑名单（`CACHE_FORBIDDEN` 原样保留）。

## 页 4 · 高级规则（organize）

### 4.1 设计意图

这是给高级用户的 YAML 工作台。界面目标：左写右看、先校验再预演最后执行；执行按钮是页面唯一危险动作，且明确标注「不受撤销保护」。

### 4.2 布局结构

```
┌ 命令栏 ───────────────────────────────────────────────────────────────────┐
│ 高级规则                             [载入配置…] [校验] [预演] [执行…]     │
├ 左编辑区 * ──────────────────────────┬ 右说明 320 ────────────────────────┤
│ 1  rules:                            │ 内置 organize 3.3.0（MIT）          │
│ 2    - folders:                      │ 可用动作：move / rename / delete     │
│ 3        - 'D:/下载'                 │ 示例模板 ▸                           │
│ 4      filters:                      │ 路径用单引号或正斜杠，双引号会报       │
│ 5        - extension: pdf            │ "found unknown escape character"     │
│ 6      actions:                      │                                     │
│ 7        - move: 'D:/下载/03_文档/'   │                                     │
├ 输出面板 180（可折叠）───────────────────────────────────────────────────┤
│ 12:04:11 配置校验通过                                                  │
│ 12:04:30 预演：将移动 12 个文件，删除空目录 2 个                          │
└───────────────────────────────────────────────────────────────────────────┘
```

| 区域 | 规格 |
|---|---|
| 编辑器 | 等宽 T6 13；行号 48 宽；语法高亮（YAML）；Tab = 2 空格；`Ctrl+Space` 插入模板；行内错误波浪线 + 底部输出面板给出行号 |
| 右说明 | 固定 320，可折叠为 0；三段：引擎版本与许可、可用动作速查、路径引号坑 |
| 输出面板 | 180 高，等宽 T5 11；按时间追加；可清空/折叠 |
| 执行 | 危险描边按钮；点击后确认框：「organize 会直接生效，本工具的撤销无法回退」→ 输入「执行」两字才可继续（沿用现版本无撤销的语义，补一道闸门） |
| 载入 | 系统打开文件对话框（.yaml/.yml）；载入后覆盖编辑器并要求确认 |

### 4.3 字体 / 字号 / 字重

页面标题 T1；编辑器 T6 13；输出 T5 11 等宽；右说明正文 T4 12，标题 T4 12 SemiBold；按钮 T3 13。

### 4.4 交互与动效

- 校验/预演：主按钮进入忙碌态，输出面板追加结果；成功/失败用消息条汇总（错误行号可点击跳转）。
- 执行：确认后状态栏进度；完成后汇总「移动 N / 重命名 N / 删除空目录 N / 失败 N」。
- 编辑器与输出面板之间可拖拽分隔条；分隔比例记忆到 settings。

### 4.5 为什么符合工具型高效 + Windows 原生

- 添加来源后自动刷新「未预览」状态；「开始迁移」在未预览时禁用（Tooltip：先预览）。
- 预览：状态栏不确定进度 + 总览逐行填目标与大小；预览结果淡入；完成后主按钮变为可用的实心按钮。
- 开始迁移：确认框列出「N 项、共 X GB、方式移动/复制」；执行中进度区可见、可取消；取消后已完成部分保留并报告。
- 断点续跑：取消/崩溃后再次进入页面时，顶部消息条「上次迁移未完成，是否继续？」+「继续 / 查看任务」。
- 回滚：确认框列出将回滚的条目；完成后状态改为「已回滚」。

### 8.5 为什么符合工具型高效 + Windows 原生

- 左表单右总览让用户「填完立刻看预演」，不用切页；预演与执行同屏减少误操作。
- 进度、取消、断点、回滚都在页面内，不用猜后台在做什么——符合工具软件的可控感。
- 表格、进度条、文件夹选择器、拖放都是 Windows 原生控件与习惯。

### 8.6 功能落点（不漏）

添加文件夹/文件、移除选中、清空、目标目录、移动/复制、重名策略、校验（小文件全部哈希）、保留来源文件名、移入回收站、并发数、预览、开始迁移、取消、断点续跑、撤销上次（整体回滚）、任务历史、导出报告、迁移总览表、逐项状态与失败原因、命令行入口 `--migrate --to <目标> [--apply] <来源…>`（保留，供脚本调用）。

### 9.4 计划任务

| 任务名 | 触发 | 行为 |
|---|---|---|
| `整理助手_清理截图` | 每天 HH:MM | 按创建时参数静默清理截图 |
| `整理助手_清理缓存` | 每天 HH:MM | 只清安全级 + 自定义目录，写 `数据\缓存清理.log` |

### 9.5 数据目录缺失告警

启动时若 `数据位置.json` 指向目录不存在：对话框（标题「数据目录找不到」）说明原路径、当前默认目录与处理办法；确定后用默认目录继续。文案与现版本一致。

### 9.6 关于 / 版本

命令面板「关于」→ 对话框：版本号、构建时间、数据目录、日志目录、开源许可入口。现有界面未提供独立关于页（仅标题），此项为补充（列待确认，不改变现有功能）。
