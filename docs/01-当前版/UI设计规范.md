# UI 设计规范（Linear 风格，v1.1.0 起；v1.2.0 扩展动效与叠放层级；v1.3.0 刷新策略与体积）

这份文档写给「以后要改界面的人」。它描述的不是审美意见，而是**已经落在 `src/web/styles.css` 里的规则**——
改界面前先看这里，改完回这里补一行，别让规范和代码分叉。

> 范围：只改视觉层。页面结构、路由、IPC、引擎调用、卡片安全边界一律没动，
> 所以「功能对照表」「前端页面契约」两份文档仍然有效。

## 1. 目标：把 Linear 的五条特征落到这个软件上

| Linear 特征 | 本项目落点 |
|---|---|
| 极简克制的色彩 | 只用黑白灰 + 一个低饱和 indigo `#5e6ad2`；红/绿/琥珀只用于「危险 / 成功 / 目标平台」三种语义，且都是 10% 透明底 + 深色字 |
| 结构优先的排布 | 侧栏 164px 灰底（1.23.0 起按内容定宽，不再留右侧空白）、主区画布灰 `#fbfbfa`、内容白卡；卡片靠 1px 发丝线分隔而不是靠阴影堆叠；行高统一 32px |
| 轻量化视觉 | 1.7px 细线图标（Lucide 风格路径，内联 SVG 无外部依赖）、4–10px 小圆角、卡片零阴影（阴影只给浮层） |
| 字体排版统一 | 内嵌 Inter 可变字体（latin / latin-ext 子集），中文走系统字体；字号只有 15 / 13 / 12 / 11 四档，行高 1.5 |
| 克制的动效 | 四档时长 120 / 160 / 220 / 280ms，曲线三档：`--ease`（状态切换）、`--ease-out`（进场收尾）、`--ease-spring`（浮层弹出）；不做位移上浮、不做图标旋转，只做底色 / 透明度 / 极小缩放；每个功能的加载态有专属 SVG 动效图标（见 4.3） |

## 3. 组件规则

- **按钮**：默认「白底 + 发丝描边」，`primary` 为 indigo 实心，`danger` 只红字红描边不实心（防误点），`ghost` 无边框。
  **禁用态统一降级为 `--surface-2` 底 + `--text-3` 字**，不再用透明度——浅底上的半透明白字读不清。
- **输入框 / 下拉**：高 30px，圆角 6，聚焦时 `box-shadow: 0 0 0 3px var(--accent-ring)`。
- **表格**：无外框、无斑马纹，只有 1px 行分隔与表头下边线；表头 12px `--text-2` 且 `position: sticky`；
  单元格 10px 内边距、行高 32px；长路径靠 `table-layout: fixed` + 省略号收，**不做横向滚动**（`--scroll` 保留 `overflow-x:auto` 兜底）。
- **侧栏**：底色 `--surface-2`，右缘 1px `--line`，**不加外边距、圆角、独立底色**——它和其余界面共用同一套令牌，
  深色下是中性黑而不是发蓝的 `#0d1117`。条目 13px / 图标 15px / 行高 30 / 圆角 6。
  悬停只加 1px `--line` 描边 + `--hover` 底；选中态是「`--nav-active` 底 + 条目**内侧** 3px `--accent` 竖条」，
  底色块与竖条**原地不动**，只把图标与文字用 `translate: 6px 0` 右移（220ms）；用独立 `translate` 属性而不是 `transform`，
  这样它和图标悬停的 `scale/rotate` 是叠加关系，不会互相覆盖（旧版整体位移会撑出横向滚动条、收轨时被裁成细条）。
  **不做模糊**：模糊在中文 13px 上只会糊成灰块，而且极难保证「移出即复位」。
  收轨 60px 时侧栏内边距收到 4px、导航不留内边距，条目 51px 宽、图标居中、不显示竖条也不位移，品牌改为透明底。
- **AI 入口是体素头像**（1.23.3 起）：侧栏「AI 助手」、整理 / 空间工具的「问助手」、AI 空态与抽屉头统一用 `SteveAvatar`（`js\ai\steve.js`，自建 8×8×8 体素，Canvas 2D 绘制），不再用 `spark` 星芒。
  槽位仍按 15px 图标设计，侧栏画布 22px 居中溢出、不推挤文字；工具条 24px、空态 38px、抽屉 18px。
  点击时头像转 360° 并在独立 canvas 上爆裂（问号 / 感叹号 + 方块粒子，800ms 自删），这是**唯一允许的装饰性爆发**，其余位置仍守「不做位移上浮、不做图标旋转」。
- **折叠组（`.section` / `.group`）**：页面级折叠组是「卡片」；**卡片内部的折叠组必须是平铺行**——
  卡里再套卡片会变成「盒中盒」，这是上一版最显乱的地方。
- **徽章**：11px，圆角 4，语义底 10% 透明 + 同色深字。
- **统计条**：数字 20px / 600 字重 / `tabular-nums`，标签 12px；项之间用 1px 竖线分隔。
- **浮层**：弹窗 460px 宽、圆角 10、`--shadow-3`、遮罩 `--scrim-strong` + `blur(3px)`；
  Toast 右下角、语义色条 + 语义图标 + 底部倒计时线；右键菜单从鼠标点缩放展开；图片预览近黑渐变底 + 图片 1px 亮边。
  叠放层级与遮罩令牌见 4.1——**弹窗必须压在图片预览之上**（预览里点删除弹的确认框曾经被盖住）。
- **工具条（`.toolbar`）**：允许换行；右侧按钮组 + 排序下拉包进 `.toolbar-tail`（`margin-left:auto`），
  窄窗时整组一起换行——不能把单个下拉甩到下一行独自站着。
- **空态**：一个 22–24px 的浅灰图标 + 13px 主文 + 12px 说明，居中，`opacity` 只有 .34——它只是氛围，不该抢注意力。
- **导航**：三组（整理与清理 / 查找与规则 / 系统），组标题 11px `--text-3`，组间 1px 分隔线；
  选中态是 `--nav-active` 底 + `--text-1` + 500 字重，**不再是蓝底蓝字**。

## 4. 动效

### 4.1 叠放层级（1.2.0 重排，解决「叠起来看不清」）

同屏叠放时靠三件事区分：**更深的遮罩、更强的阴影、更实的边框**。层级如下（`styles.css` 顶部注释同步）：

| 层 | z-index | 遮罩 | 阴影 | 说明 |
|---|---|---|---|---|
| 页面内容 | — | — | 卡片零阴影 | 正常态 |
| 图片预览 `.preview-mask` | 80 | 近黑径向渐变 `#0c0d10 → #050607` | 图片自带 `0 30px 80px` | 全屏看图 |
| 全屏处理中 `.overlay` | 86 | `--scrim` + `blur(3px)` | `--shadow-3` | 长任务进度条 |
| 弹窗 `.modal-mask` | 88 | `--scrim-strong` + `blur(3px)` | `--shadow-3` | 确认 / 表单，**高于预览** |
| 右键菜单 `.ctx-menu` | 90 | 无 | `--shadow-3` | 从鼠标点缩放展开 |
| Toast `.toasts` | 95 | 无 | `--shadow-3` | 永远在最上面 |

新增遮罩令牌：`--scrim`（浅 `rgba(14,15,18,.38)` / 深 `rgba(0,0,0,.58)`）、
`--scrim-strong`（浅 `.54` / 深 `.72`）、`--scrim-blur`、`--shadow-3`。

Esc 只关最上面一层：`UI.preview` 与「清理截图」页自带的看图器都在 `modal-root` 有子节点时直接 return（`shots.js` 的 `onKey` 同样加了判断）；弹窗只在自己是 `modal-root` 最后一个子节点时响应。

### 4.2 时长与曲线

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--dur-1` | 120ms | 悬停底色、行高亮 |
| `--dur-2` | 160ms | 透明度、关闭动画、骨架换内容 |
| `--dur-3` | 220ms | 页面入场、展开收起、浮层弹出 |
| `--dur-4` | 280ms | 大块内容（预览图、长列表整块过渡） |
| `--ease` | `cubic-bezier(.16,1,.3,1)` | 状态切换默认值 |
| `--ease-out` | `cubic-bezier(.22,.61,.36,1)` | 进场收尾 |
| `--ease-spring` | `cubic-bezier(.34,1.32,.64,1)` | 弹窗 / 菜单 / Toast 弹出（回弹但不夸张） |

已经有的过渡：页面入场（8px 上浮 + 淡入，子块 0/22/38/52/62ms 错开，超过第 4 块不再累加）、
侧栏折叠（`grid-template-columns` 过渡，窄窗自动收轨也是同一段）、
卡片/行/按钮底色与描边、截图卡悬停（上浮 1px + 图 1.5% 放大）、折叠组 0fr→1fr、图片预览缩放、Toast 进出。

### 4.3 每个功能的加载图标（`UI.loader(kind)` / `UI.skeleton(rows, kind)`）

全部手写 SVG（24 网格、1.6px 描边、只用 `currentColor`，横向参照 Lucide 的线宽与端帽，未引入第三方图标包），
动画写在 `.ldr-*` 里，元素本身只是骨架：

| kind | 形态 | 用在哪 |
|---|---|---|
| `scan` | 方框内一条扫描线上下移动 | 整理文件、空间工具（扫描/删除） |
| `cache` | 三层堆叠依次点亮 | 清理缓存 |
| `apps` | 2×2 方块依次缩放 | 卸载程序 |
| `shots` | 相框 + 山形线描画 | 清理截图 |
| `search` | 放大镜镜片虚线旋转 | 搜索 |
| `rules` | 文档三行依次画出 | 高级规则 |
| `migrate` | 两侧门 + 箭头循环推进 | 数据迁移 |
| `log` | 三行文字 + 光标闪烁 | 日志 |
| `settings` | 齿轮慢转 + 中心呼吸 | 设置 |
| `spin` | 单弧旋转（兜底） | 其它长任务 |

加载块 = 左边 26px 动效图标 + 右边骨架条（`.loading-block`），一眼能看出「正在加载哪一块」；
长任务的遮罩卡也用同一套图标 + 一条不确定进度条；Toast 带语义图标与底部倒计时线。

### 4.4 降级

`prefers-reduced-motion: reduce` 时：所有动画时长压到 1ms、无限循环动画停止，
加载图标停在可读的静态形态（虚线不抽动、骨架不 shimmer、Toast 倒计时线不缩），
页面入场与侧栏动效整体关闭，只留 `opacity` 变化。

### 4.5 行入场（1.2.1 新增）

扫描结果的行按插入顺序淡入，**只给前 10 行错峰**（16ms 一档），第 11 行起统一 160ms 起——行数再多也不会越拖越慢。

- 实现：`organize.js` 的 `renderFileRow` 给 `<tr>` 加 `class="row-in"`，样式在 `styles.css` 的 `.row-in` 系列。
- 为什么只加在这一处：该页的行是「只追加、不重建」，勾选与「显示更多」都不会重播动画；而「卸载程序」页筛选时整表重建，若也挂 `row-in`，打字时整屏会闪。
- 行只用 `opacity`，不用 `transform`：`<tr>` 上的位移会影响行高与边框绘制。
- 降级：`prefers-reduced-motion` 下 `.row-in` 直接 `animation: none`。

### 4.6 刷新策略：什么时候重绘、什么时候只落定（1.3.0）

旧版「每点一下都闪一下」不是动画写得重，是**刷新粒度太粗**：一次操作 = 整页重挂载 + 整块重建 + 进场动画重播。

**a) 同页导航短路**（`app.js` 的 `navigate`）：已经在 A 页再点 A，只同步 hash 与导航高亮，**不重建 DOM、不重置滚动**。像素比对验证：连点后整屏差值 0。

**b) 进场动画只在挂载时存在**（`data-enter`）：新挂载的 `.page-body` 带 `data-enter="1"`，700ms 后摘掉；CSS 的 rise-in 只挂在 `.page-body[data-enter] > *` 上。页内重建（排序、翻页、扫描完成、换视图）不会重播。

**c) 页内换内容用 `UI.softIn(container)`**：容器内容被替换后加 110ms 的 `.soft-in`（只淡 `.72 → 1`，**不位移**）。
用在哪：`apps.js` 表格、`cache.js` 分组、`shots.js` 结果区。
不用在哪：打字过滤（每敲一键都重建，淡入会变闪烁）——`apps.js` 用 `S.typing` 在输入后 400ms 内跳过；`selectAll` / `invertSelection` 只改勾选状态，也不淡。

**判断标准**：这次操作**换掉了节点**吗？换了 → `softIn`；只改状态 → 什么都不做，CSS 过渡自己会处理。

### 4.7 已删除的

按钮 `translateY(-1px)` 上浮、图标 `rotate(-5deg)`、六色图标轮换、多光标搭建动画——它们只是装饰，且让界面显得跳跃。

### 4.8 思路行（1.22.0 新增，AI 助手的思考动画）

搬家自 React Bits 的 ThoughtLine（见 `THIRD_PARTY.md`），实现是 `js\ai\thoughtline.js` + `styles.css` 的
「思路行（thoughtline.js）」段化名 `.tl*`；参数口径与原版一致（`label` / `doneLabel` / `glyph` /
`steps` / `breathPeriod` / `breathDepth` / `shimmer` / `settleDuration` / `settleBlur` /
`collapsible` / `collapseOnSettle` / `showTimer` / `onSettle`）。

| 阶段 | 视觉 | 口径 |
|---|---|---|
| 跑着 | 四角星与句子在谷值→1 之间呼吸；一道亮带横扫句子 | `breathPeriod=1.6s`、`breathDepth=.45`；有微光时句子不呼吸，呼吸只留 glyph |
| 过程 | 每步一行：跑着的是 0.4em 呼吸点，跑完变勾，失败变叹号（`--danger`） | 摘要超长省略号 + `title`；行只淡入位移 4px |
| 落定 | 句子交叉淡入淡出 + 2px 模糊，计时器滑到句尾，过程折成一行 | `settleDuration=350ms`、`settleBlur=2px`；计时器用 `transform` 不碰布局 |
| 折叠 | 点标题行摊开/收起，chevron 翻转 | `grid-template-rows: 0fr ↔ 1fr`，与 4.2 的折叠组同一手法 |

- 颜色：工作态整行走 `--text-1`（微光渐变肩部 60% 不透明度，两套主题都够读）；落定句子 `opacity .8`、glyph 收到 `.4`；一行里只有失败标记用强调色，其余全是文字色。
- 降级：`prefers-reduced-motion` 关微光、关位移、关过程行入场，只留淡入淡出；JS 侧同步把呼吸深度压到 0.2、周期 ×1.5（`AIMotion.prefersReduced()`）。
- 无障碍：标题是 `<button>`（无步骤时 `tabindex=-1` 且不给 `aria-expanded`），整句结论写进 `role="status"` 的隐藏节点，朗读成「查了 3 项 · 用时 4.2 秒」。

### 4.9 AI 助手：归档左栏 + 锚定气泡（1.23.9 新增）

**布局**（`styles.css` 的「AI 助手（1.23.9）」段，`.ai-page` 起）

| 区域 | 口径 | 说明 |
|---|---|---|
| `.ai-rail` | 208px 定宽（<1120px 收 176px） | 新对话在顶、归档列表居中滚动、设置沉底；右侧 1px `--line` 分隔 |
| `.ai-new` | 高 32px、1px 边框 | hover 上 `--hover`，按下 `scale(.985)` |
| `.ai-sess` | 32px 行、`--radius` 圆角 | 悬停浮 `--hover`；当前会话 `--surface-2` + 左侧 2px 竖条；删除按钮默认 `opacity:0`，悬停/键盘聚焦才显形 |
| `.ai-page-chat` | `max-width:760px` 居中 | 输入框钉在列底，消息区 `.ai-scroll` 自己滚 |
| 滚动条 | AI 界面全程不显示 | `scrollbar-width:none` + `::-webkit-scrollbar{width:0}`，滚轮/键盘照常 |

高度链是这一页最容易崩的地方：`.page-host` / `.page-body` 默认 `min-height:min-content`，
消息一多会把整页顶高、输入框被推出视口。AI 页用三条 `:has()` 把这条链改成定高——
`.page-host:has(> .page-body > .ai-page)`、`.page-body:has(> .ai-page)`、
`.scroll:has(.ai-page)` 全部 `min-height:0; height:100%; overflow:hidden`。
再加一条：`.ai-scroll` 必须自己 `position:relative`，否则思路行里无坐标的 `absolute`
隐藏节点会把定位祖先落到 `body`，撑出文档级外层滚动条。

**左栏收起**（1.23.10 新增）

- 宽度只由一个变量决定：`.ai-page{--ai-rail-w:208px}`，收起态
  `.ai-page[data-rail="closed"]{--ai-rail-w:0px}`；`.ai-rail` 的 `flex-basis`/`width` 都读它，
  所以展开收起不会出现「收一半」的中间宽度。
- 收起时同时归零 `margin-right`/`padding-right`、`opacity:0`、`border-right-color:transparent`，
  内容 `pointer-events:none`——视觉上整栏退场，而不是留一条空槽。
- 开关不跟着栏一起消失：展开态在「新对话」右边（`.ai-rail-toggle`，26×32）；
  收起态挪到对话区左上角的留白里（`.ai-main-toggle`，26×26），靠
  `.ai-page[data-rail="closed"] .ai-main{padding-left:34px}` 让出位置，
  **不浮在正文上**，所以任何窗口宽度都不会压住内容。
- 过渡走 `--dur-3` 与 `--ease`：宽度、间距、内边距、透明度、分隔线颜色一起变；
  `prefers-reduced-motion` 下自动变成立即切换（`styles.css` 全局降级段已覆盖）。
- 状态存 `localStorage['ai.rail.closed']`（`'1'`/`'0'`），下次进 AI 页保持上次的样子；
  键盘 `Ctrl/Cmd+B` 切换，焦点跟着开关走（收起后焦点落到 `.ai-main-toggle`）。

**锚定气泡**（`composer.js` 的 `createPopover`，CSS 段 `.dac-pop`）

- 面板挂到 `body`、`position:fixed`，贴触发块上沿向上展开，间距 `POP_GAP=8`；上方空间不够才翻到下方
  （`shell.dataset.side="up"|"down"`，`transform-origin` 跟着换）。
- 触发块**不淡出、不形变**：只置 `data-open` / `aria-expanded`，所以点开菜单时胶囊还在、还能再点一次收起。
- 展开动画交给 CSS 过渡（`opacity` + `translate3d/scale`，`--dur-2`），JS 只在打开时算一次位置；
  `prefers-reduced-motion` 降级为纯淡入。
- 关闭手势：点面板外、Esc、任何滚动（菜单自身滚动除外）、窗口 resize 重排。
- 列表高度：`.dac-menu-scroll` 上限 260px，超过就自己滚，不再截成两行半。

### 4.10 设置页：获取模型 / 上下文窗口（1.23.13 新增）

三档推理强度按窗口比例分配：简单 25% / 中度 50% / 深度 75%，夹在 `[2000, 窗口-2000]`；
composer 的上下文占用环分母 = 当前模型窗口，换模型时同步换分母。

**档位上必须写出这一档的 token 数（1.23.18 起）**

| 位置 | 规格 | 说明 |
|---|---|---|
| 档位标签 | `.re-stop-name`（11px）+ `.re-stop-val`（10px 等宽灰字）两行 | `简单/16K`、`中度/32K`、`深度/48K`；窗口未知时不显示第二行，不编造 |

## 7. 维护约定（避免重演旧债）

1. **只改令牌，不追加覆盖块**。上一版 `styles.css` 有四处「文件末尾再写一遍同名规则」的叠压
   （`.dir-row`、`.shot-item`、`--row-h` 各两套），排查时根本看不出哪条生效。现在的文件是**单遍定义**。
2. **页面 JS 不许写死颜色/字号**；必须传宽度时用 `style.width`，颜色一律 `var(--token)`。
3. 新增可折叠区块请直接用 `UI.section()`，卡片里的用它就会自动平铺，不需要额外类名。
4. 字体只内嵌 latin 子集（`src/web/assets/fonts/`，OFL 1.1，见 `docs/当前版-第三方许可.txt`）；
   中文依赖系统字体，别再往包里塞中文字体。
5. **页内刷新先问「换没换节点」**：换节点用 `UI.softIn()`，只改状态就交给 CSS 过渡；
   不要在重建函数里加进场动画，那会变成每次操作都闪一下。
6. **体积守则**：字体只留一个 latin 子集（48 KB，去掉 latin-ext 省了 85 KB）；
   新增 CSS 前先把类名在 `src\web` 里搜一遍，确认不是死规则再写（本文件是单遍定义，不留覆盖块）。
7. **弹窗里不要套边框盒子**：`.modal .section` 与 `.card .section` 共用同一套平铺规则，
   弹窗内的「概况 / 列表」直接用 `UI.section()` 就是平铺行，不要再套 `.card` 或加边框。
8. **表格里的时间是秒、卡片里是毫秒**：`UI.fmtTime(v)` 吃秒（索引条目的 `built_at`），
   `UI.fmtDateTime(v)` 吃毫秒（要先 `* 1000`）。写错不会报错，只会显示成 1970 或 58845 年。

## 9. AI 页的 Claude 皮肤（1.29.0 起）

AI 页是唯一一处不跟全站蓝色强调走的地方：它按 Claude 的外观重画过，令牌与规则全部来自
参考包 `dsh-claude-style 0.21.5`（`lib\client.js` 的调色板块 + `docs\STYLE.md`）。
作用域只有 `.ai-page`，别的页面照样读 `:root` 上的变量。

| 项 | 浅色 | 深色 |
|---|---|---|
| 卡面 / 侧栏 | `#ffffff` / `#fafafa` | `#1f1f1f` / `#1f1f1f` |
| 描边 l1 / l2 | `#e9e9e9` / `#dedede` | `rgba(255,255,255,.09)` / `.18` |
| 墨色 1 / 2 / 3 / 4 | `#161616` / `#70696b` / `#91888b` / `#b2acae` | `#fdfdfd` / `#beb6b8` / `#9c9395` / `#7d7577` |
| 用户气泡 | `#f4f2f3` | `rgba(255,255,255,.06)` |
| 强调（仅此页） | `#d97757`，hover `#c46343` | 同色 |

形状与节奏：圆角阶梯 4 / 8 / 16，描边一律 1px，分隔线 0.5px（`--cl-hair`），间距 4px 倍数。
动效 80 / 120 / 150 / 250 / 320ms，缓动 `cubic-bezier(.22,1,.36,1)`、
入场 `cubic-bezier(.34,1.3,.64,1)`。

对话区规则：

- 不挂「你 / 助手」标签：用户那句靠右侧浅底气泡（16px 圆角，右下 4px），
  助手回答不套气泡、14px / 1.72，与正文同字号同字重。
- 思考是一张卡，不是一段缩进列表：标题行 36px、左右内缩 12px；明细行 36px，
  行间一道 0.5px 分隔、首行上方不重复画线；展开后卡内滚动，上限 `min(400px, 50vh)`。
- 等待行是 16px 盒子里的三颗点（错相呼吸 + 轻上浮），不是图标；
  计时器推到行尾当 caption（`11.5px`、等宽数字、`--cl-ink-4`）；
  复制按钮悬停标题行才出现。
- 过程行不带图标：状态靠文字颜色（失败转 `--danger`）。
- 焦点：输入框只加深投影，不拿强调色描边（强调色留给主按钮）。

维护约定：新增 AI 页样式一律先用 `--cl-*` 令牌，不在规则里写十六进制；
需要在别的页面复用这套外观时，把令牌提到共用选择器，而不是复制数值。
