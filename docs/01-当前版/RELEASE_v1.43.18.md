## 本版重点更新

### 1. 官方 GitHub 仓库迁移至 `3347567186/QDisk`
- 软件内置在线更新源（`updater.rs`）、仓库白名单锁仓校验（拒绝已废弃旧仓库路径）、设置页跳转链接、发包脚本与 GitHub Actions 全面迁移至 `3347567186/QDisk`。

### 2. `[Q]Disk` 图标与字标一体化锁排 & Windows 任务栏图标强制同步
- 桌面端侧栏顶部与官方网站统一启用 **`[Q]Disk`** 融合品牌锁排：`Q` 矢量图标直接作为首字母，后接定制 `Disk` 字标（`i` 圆点呼应 `Q` 盘心暖朱红）。
- 重建 7 档 Windows 原生 DIB+PNG `icon.ico` 与高分 PNG 资源，启动时主动发送 Win32 `WM_SETICON`（`ICON_BIG` / `ICON_SMALL`）与 `set_icon`，彻底解决任务栏显示旧图标的问题。

### 3. 侧栏 AI 助手入口重构（经红队对抗审查与回归验证）
- 仅重构侧栏顶部 AI 助手入口为精巧的 **AI 指令卡**，整合头像槽、双行信息、暖朱红强调指示与折叠轨自适应，并修复折叠裁切、双重提示气泡、动效降级与重建防泄漏等边界条件。

### 4. 官方网站去噪重构与双向渐进浮现动效
- 删除所有动画暂停/控制按钮、重复跑马灯、悬浮底部导航坞、冗余沙盒及首屏版本胶囊；为上下滚动打造舒缓柔和的渐进浮现与首屏透视舒展动效。
