# 轻盘 QDisk · 发包与在线更新指南

本软件内置官方 GitHub Releases 在线更新引擎（仓库 `Bireo/QDisk`），**用户端零配置**（设置页不出现任何网址输入框，打开「设置 → 版本与在线更新」直接点击即可检查、下载、校验并重启安装），同时自动识别 **安装版（NSIS）** 与 **便携版（ZIP）**。

---

## 一、日常发版只需 2 条命令

```powershell
# 1. 自动递增版本号 + 跑全量测试门禁 + 构建安装包与便携包 + 生成 release\latest.json 与 SHA256SUMS.txt
pwsh -File .\build.ps1 -Bump patch

# 2. 一键发布到 GitHub Releases（自动上传安装包、便携包、latest.json、SHA256SUMS.txt）
pwsh -File .\tools\publish-release.ps1 -UploadGitHub
```

发布完成后，所有已安装用户的软件会在启动 6 秒后静默检测到新版本，或在「设置 → 版本与在线更新」点击「立即检查更新」一键升级。

---

## 二、测试版通道（Beta）发包

```powershell
pwsh -File .\build.ps1 -Version 1.44.0-beta.1 -Channel beta
pwsh -File .\tools\publish-release.ps1 -Version 1.44.0-beta.1 -Channel beta -UploadGitHub
```
稳定版用户不会收到 Beta 推送；只有在设置页切到「测试版」的用户才会收到。

---

## 三、开发者本机联调（仅放行本机回环，不暴露到界面）

```powershell
# 终端 1：启动本机测试更新源
pwsh -File .\tools\publish-release.ps1 -ServeLocal -Port 18765

# 终端 2：通过仅限 127.0.0.1 的开发环境变量启动程序联调
$env:TIDY_UPDATE_FEED = 'http://127.0.0.1:18765/latest.json'
.\tidy-assistant.exe
```

> 安全说明：环境变量 `TIDY_UPDATE_FEED` 在底层强制校验仅允许本机回环（`127.0.0.1` / `localhost` / `::1`），任何远端域名都会被忽略；生产态所有更新请求与下载跳转均锁定在官方 GitHub 受信任域名 + HTTPS + SHA-256 + 二进制魔数校验之内。
