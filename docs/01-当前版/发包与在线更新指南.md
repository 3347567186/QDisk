# 整理助手 · 发包与在线更新指南

本软件内置原生在线更新引擎（零新增外部依赖，支持**安装版 NSIS** 与 **便携版 ZIP** 双形态自动识别升级），强制远端 **HTTPS + SHA-256 完整性校验 + 二进制文件头校验 + 便携版失败自动回滚**。

---

## 一、支持哪几种发包托管方式？

客户端「设置 → 版本与在线更新 → 更新源地址」支持以下任意一种 HTTPS 地址：

1. **GitHub Releases（推荐，免费全球 CDN）**
   - 直接填：`https://github.com/<你的用户名>/<仓库名>/releases/latest/download/latest.json`
   - 或填 GitHub 原生 API：`https://api.github.com/repos/<你的用户名>/<仓库名>/releases/latest`
2. **国内对象存储 / 静态站点（Gitee / 阿里云 OSS / 腾讯云 COS / Cloudflare R2 / 自建 Nginx）**
   - 直接填：`https://your-domain.com/releases/latest.json`
3. **本机联调测试（仅放行本机回环 HTTP）**
   - 填：`http://127.0.0.1:18765/latest.json`

## 二、每次发版 2 步完成上线

### 方式 A：构建 + 生成发包清单一步到位
```powershell
# 1. 构建新版本（自动跑全量测试门禁、更新安装包与便携包、并自动产出 release\latest.json 与 SHA256SUMS.txt）
pwsh -File .\build.ps1 -Bump patch -ReleaseBaseUrl "https://your-domain.com/releases/"

# 2. 将 release\ 下这 4 个文件上传到你的服务器/对象存储即可：
#    - latest.json
#    - SHA256SUMS.txt
#    - TidyAssistant_<版本号>_x64-setup.exe
#    - 整理助手_<版本号>_便携版.zip
```

### 方式 B：一键发包到 GitHub Releases
```powershell
pwsh -File .\build.ps1 -Bump patch
pwsh -File .\tools\publish-release.ps1 -GitHubRepo "你的用户名/TidyAssistant" -UploadGitHub
```

### 方式 C：本机 10 秒真实端到端体验
```powershell
pwsh -File .\tools\publish-release.ps1 -ServeLocal -Port 18765
```
打开软件 → **设置 → 版本与在线更新** → 更新源填入 `http://127.0.0.1:18765/latest.json` → 点击「立即检查更新」。
