# 整理助手 · 开源发布与 7 天社区推广迭代方案

本方案严格遵循四条开源冷启动原则：
1. **先展示 Use Case 与 GIF/Demo，别上来吹技术栈**；
2. **第一人称、说人话的接地气标题**，拒绝“重磅开源/全新发布”腔；
3. **针对每个社区的置顶帖气质重写钩子**，绝不全网复制粘贴；
4. **每天只发 1 个社区**，根据点赞、评论质疑和提单反馈迭代下一天的文案与产品细节，寻找真正的 Product-Market Fit。

---

## 一、发帖前准备：先录 3 段 10 秒核心 GIF（最重要！）

用 ScreenToGif / OBS 录 3 段 1280×720、每段 ≤ 10 秒的短 GIF，放到 `docs/assets/` 并在 `README.md` 取消注释即可：

1. **`demo-organize.gif`（下载目录秒整理 + 一键撤回）**：
   - 画面：打开塞满 100 个杂乱文件的「下载」目录 → 点「扫描」→ 点「开始整理」变成干净分类文件夹 → 再点「撤销」瞬间全部还原。
   - 传达卖点：**敢放心点，因为真能撤回**。
2. **`demo-archive.gif`（大包四档调速 + 实时暂停 + 冲突并存）**：
   - 画面：拖入一个大压缩包 → 切到「超线程」起飞 → 点「暂停」立刻停住并显示进度横幅 → 解压撞名时弹出「直接覆盖 / 二者并存」选择框。
   - 传达卖点：**无广告、能真暂停、不覆盖丢文件**。
3. **`demo-ai.gif`（AI 助手提案审批）**：
   - 画面：问「帮我看看下载目录里哪些大文件可以清理」→ AI 扫完列出清单并生成「审批提案卡」→ 用户勾选确认才执行。
   - 传达卖点：**AI 干活不越权，删什么由你拍板**。

## 二、7 天错峰发帖排期与各社区定制钩子

### Day 1 · GitHub + V2EX（`/go/share` 分享创造）
- **社区气质**：反感营销腔、极度在意安全/隐私/有没有后门、喜欢真实个人痛点与技术诚意。
- **标题**：`受够了 C 盘天天爆红和乱成一团的下载目录，我花几个月给自己写了个全本地的 Windows 整理工具（开源无广告）`
- **钩子切入点**：
  - 开头直接放 1 张「整理前 vs 整理后 + 一键撤销」动图；
  - 重点讲**为什么敢拿它整理自己硬盘**：全本地无遥测、所有删除/迁移先预演、自带硬编码系统目录白名单保护、压缩包支持暂停与撤回、内置 GitHub Releases 自动更新且强制 SHA-256 校验；
  - 结尾诚恳求挑刺：“你们最怕清理工具误删什么？评论告诉我，我加进硬保护名单”。

### Day 2 · 少数派 / 知乎（效率工具与 Windows 话题）
- **社区气质**：重场景工作流、重“桌面整洁感”与“省心”，不爱看代码。
- **标题**：`我是怎么用一个小工具，把 600 个下载文件和爆红的 C 盘在 1 分钟内收拾干净的`
- **钩子切入点**：
  - 用前后对比图讲 3 个真实生活痛点：微信/截图堆满桌面、下载目录找合同找不到、想把 20GB 软件从 C 盘搬去 D 盘又怕搬坏；
  - 重点强调**便携版解压即用 + 每一步都能撤回 + 自带在线更新无需折腾配置**。

### Day 3 · 小众软件（Appinn 论坛）/ 异次元投稿
- **社区气质**：最爱“免费、开源、单文件/便携、解决一个小而具体的烦心事”。
- **标题**：`整理助手 - 我把文件分类、截图缓存清理、无广告解压和跨盘迁移做进了一个开源小工具里`
- **钩子切入点**：
  - 突出「便携版 25 MB 打包即走」「零广告零捆绑」「能把解压软件 + 清理工具 + 搜索工具合而为一，还自带可选本地 AI 副驾」。

### Day 4 · Linux.do / 掘金（偏极客与折腾向）
- **社区气质**：喜欢看真干货、踩坑复盘与“真·工程细节”。
- **标题**：`为了干掉广告弹窗和 C 盘焦虑，我做了一个开源 Windows 整理工具：顺便聊聊压缩引擎暂停、防路径穿越和跨卷回滚踩的坑`
- **钩子切入点**：
  - 先用 2 句话展示工具能干嘛 + 动图；
  - 再分享 2 个让人直呼内行的工程故事：为什么普通压缩工具点击暂停没反应（高频重绘吃掉点击事件）、跨盘迁移如何靠 WAL 日志保证断电不丢数据。

### Day 5 · B 站 / 小红书（30 秒极速对比短视频）
- **社区气质**：前 3 秒必须给视觉爽感，严禁念说明书。
- **标题**：`花 3 秒钟把乱成灾难的下载文件夹变清爽！我自己写的免费开源 Windows 神器`
- **视频节奏**：0–3s 杂乱桌面/爆红 C 盘 → 3–15s 一键分类 + 撤回 + 超线程解压暂停 → 15–25s C 盘搬家腾出几十 GB → 25–30s 开源免费获取方式。

### Day 6 · Reddit（`r/windows` / `r/software` / `r/opensource`）
- **社区气质**：遵守各版自荐规则（如 `r/opensource` 允许开源自荐），英文要极度克制、真实、不吹牛。
- **Title**：`I got tired of my messy Downloads folder, ad-filled archivers, and red C: drive, so I built an open-source, local-only Windows tidy tool`
- **Hook**：Bullet 3 concrete daily annoyances + GIF + MIT license + "No telemetry, dry-run before every action, one-click undo, SHA-256 verified auto-updates."

### Day 7 · Hacker News（`Show HN`）
- **社区气质**：极度欣赏“从第一性原理把小事做到极致安全可靠”的个人作品。
- **Title**：`Show HN: TidyAssistant – Local-first Windows file organizer, fast archiver, and transactional drive migrator`
- **First Comment**：讲清楚个人动机、为什么不依赖 Electron、为什么宁愿自己写基于 WAL 的跨卷回滚和 SHA-256 双形态更新器，真诚欢迎架构与安全红队评审。
