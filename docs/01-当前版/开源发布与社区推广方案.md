## 二、7 天错峰发帖排期与现成定制模板（按社区重写钩子）

### Day 1 · V2EX（`/go/share` 分享创造）
- **社区气质**：极反感营销腔、极度在意有没有后门/遥测/误删风险，喜欢克制真诚的个人作品。
- **高热标题**：
  > `受够了 C 盘天天爆红和弹广告的解压软件，我花几个月给自己写了个全本地的 Windows 整理工具（开源 / 20MB / 每步可一键撤回）`
- **正文模板**：
  > 前几个月电脑下载目录堆了几百个文件，C 盘又经常莫名其妙爆红。市面上的免费清理和解压软件不是带弹窗就是偷偷塞后台服务，自己写脚本又怕手滑删错，所以干脆花了些时间给自己写了个开源小工具 **轻盘 QDisk**（MIT 协议，安装包 20.7 MB，也有免安装便携版）。
  >
  > 先放 1 张实际界面图 / GIF（建议放「扫描预演 + 一键撤回」或「AI 查 C 盘」图）。
  >
  > 我自己最在意的是「安全感」，所以核心做了几件事：
  > 1. **先预演，后悔 1 秒全撤回**：整理文件前先列出分类结果和跳过原因，自动绕开 `.git` 代码仓库和系统目录；实测 1000 个文件 1.8 秒整理完，不满意 1.4 秒原路还原。
  > 2. **C 盘排查 + 可选本地 AI（但绝不越权）**：可以接本地模型或自带 API，问它谁占了 C 盘，工具调用过程透明可查；点击路径优先在软件内置浏览器里定位高亮（绝不手滑跑 `.exe`，也保留了系统资源管理器按钮）；涉及删除全变成审批勾选卡片，你不点确认绝不动硬盘。
  > 3. **顺手干掉了弹窗解压软件**：内置 7 种格式（ZIP/7Z/RAR/TAR 等）多核解压，支持真暂停、解压重名选「二者并存」，覆盖错了还能撤回。
  > 4. **全本地、零遥测**：数据全留在本地目录，不上传文件列表；内置更新强制核对 GitHub Releases 的 SHA-256。
  >
  > GitHub 仓库：https://github.com/Bireo/QDisk  
  > 官网演示：https://bireo.github.io/QDisk/
  >
  > 真诚来求各位挑刺：**你们平时用 Windows 清理或整理工具时，最怕它误删哪类文件或目录？** 评论告诉我，我直接加进底层的硬编码保护白名单里。

### Day 2 · Reddit（`r/opensource` 首选；次日视反馈再决定 `r/windows` / `r/software`）
- **社区气质**：务必遵守各版块自荐规则（`r/opensource` 欢迎作者展示开源项目）；英文务必克制、不吹嘘、直接亮 MIT 开源与无遥测。
- **Title**：
  > `I got tired of my messy Downloads folder, ad-filled archivers, and a red C: drive — so I built a 20MB, local-only Windows tool with dry-run & 1-click undo`
- **Post Body**：
  > Hey everyone,
  >
  > I kept running into the same three Windows annoyances: a chaotic Downloads folder I was afraid to bulk-sort, ad-ridden archive utilities, and a red `C:` drive where I never knew what was actually safe to delete.
  >
  > So I built **QDisk** — a free, MIT-licensed, local-only Windows 10/11 desktop app (~20.7 MB installer, or portable ZIP) designed around one rule: **nothing risky happens without a preview and a way back.**
  >
  > **What it actually does:**
  > - **Dry-Run File Organizer + 1-Click Undo**: Previews every move and skips Git repos / system folders / active downloads automatically. In local tests, 1,000 mixed files sort in ~1.8s and undo cleanly in ~1.4s.
  > - **Approval-Gated Local AI Disk Triage (Optional)**: Ask what's eating your drive; every local tool call and latency is inspectable, clicking a file path safely highlights it inside QDisk (never executes `.exe` files), and any cleanup becomes a checkbox approval card you have to confirm.
  > - **Ad-Free Multi-Core Archiver**: Supports ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ with 4-tier CPU pacing, true chunk-level pause/cancel, Keep-Both conflict prompts, and single-slot undo.
  > - **Tiered Cache Cleanup & Crash-Safe Drive Migration**: Separates safe rebuildable caches from personal data, reads Authenticode publisher signatures on large files, and verifies hashes with transaction logs when migrating folders across drives.
  >
  > No telemetry, no account required, SHA-256 verified updates directly from GitHub Releases.
  >
  > - Repo (MIT): https://github.com/Bireo/QDisk
  > - Live preview site: https://bireo.github.io/QDisk/?lang=en
  >
  > Would love honest feedback — especially if there's any folder/app data path you think should be hard-protected by default!

### Day 3 · Linux.do / 掘金（偏极客与工程踩坑向）
- **社区气质**：最爱看「真实痛点 + 真踩坑复盘 + 透明源码」，不要写广告，写工程故事。
- **高热标题**：
  > `为了干掉 C 盘焦虑和弹窗全家桶，我自己撸了个 20MB 的 Windows 工具：顺便聊聊让 AI 不瞎删文件、0.31ms 强制断连和跨盘回滚踩的坑`
- **正文结构钩子**：
  1. 开头 3 行 + 1 张动图：先让人秒懂这工具解决什么日常问题。
  2. 挑 **3 个让人直呼内行的真踩坑**：
     - **坑 1（Windows 路径与权限）**：`Path::exists()` 在 `WindowsApps` 上会吞掉 `ERROR_ACCESS_DENIED` 谎报“目录不存在”；带点版本号目录（如 `157.0.4341.60`）容易被前端当文件误弹资源管理器。怎么靠 Rust `symlink_metadata` + 最近可读上级回退 + 跨 UAC 自动续跳解决的。
     - **坑 2（AI 卡死不吐字）**：WinHTTP 挂起时取消请求为什么普通方案会卡 60 秒？怎么靠跨线程直关请求句柄做到实测 `0.31 ms` 真断连。
     - **坑 3（压缩包真暂停与跨盘迁移）**：为什么很多工具点暂停没反应？以及怎么靠单槽原子撤回防止压缩包备份撑爆硬盘。
  3. 结尾附 GitHub 地址，邀请同行来做代码与安全红队评审。

### Day 6 · Hacker News（`Show HN`）
- **社区气质**：全球最看重“第一性原理、安全克制、实测数据、拒绝 Electron 臃肿”的极客社区。
- **Title**（严格 ≤80 字符、克制清晰）：
  > `Show HN: QDisk – 20MB local-first Windows organizer, archiver & approval-gated AI`
- **Author First Comment（发帖后 1 分钟内立刻自评）**：
  > Hi HN, I'm the author of QDisk.
  >
  > I built it because I wanted one lightweight, zero-telemetry Windows utility to replace a pile of ad-heavy cleaners and archivers — without ever risking silent data loss.
  >
  > A few engineering choices I'd love feedback on:
  > - **No Electron / zero frontend framework**: Tauri v2 + vanilla JS (~2 MB UI, 0 `node_modules`) + Rust native archive/path-probing layer + persistent Python engine (20.7 MB NSIS installer).
  > - **Safety before convenience**: Every file move previews first (1,000 files sort in 1.8s, undo in 1.4s). Clicking any path in AI results probes the filesystem in Rust and highlights the file inside QDisk instead of launching `.exe`s or blindly shelling out to Explorer; ACL-blocked paths like `WindowsApps` fall back to the nearest readable parent with optional one-click UAC resume.
  > - **Real abort & real pause**: Closing stalled WinHTTP handles cross-thread in Rust gives ~0.31 ms stop latency; the 4-tier Rust archiver pauses/cancels at chunk granularity with ZIP Slip / 32 GiB bomb guards and single-slot overwrite undo.
  >
  > All 370+ automated tests (Python, Rust, and headless UI/website suites) run before every release build. Happy to answer questions or hear where our safety boundaries can be stronger!
