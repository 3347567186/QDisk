# 页面模块契约（Tauri 正式版）

所有页面是独立文件，注册到 `window.Pages`，由 `app.js` 路由调用。**不要修改**除自己负责的
`web/js/pages/*.js` 以外的文件。

## 注册方式

```js
window.Pages = window.Pages || {};
window.Pages.shots = {
  title: ['清理截图', 'Screenshots'],   // [中文, English]
  async mount(root) {
    // root 是一个空的 <div class="page-body">，每次进入页面都会重建
    root.appendChild(h('div', { class: 'card' }, '...'));
  }
};
```

- `mount` 可重复调用，不需要手动清理（root 每次都是新的）。
- 可选 `jump(payload)`：别的页面带着载荷跳进来时由 `App.jump()` 调用，
  页面已挂载也会调（不重挂载）。载荷是 `{ paths: [...], action, why }`。
  没实现的页面退回普通切页；工具页、压缩包页已实现（1.36.5）。
- 所有异步调用都要 try/catch，失败用 `UI.toast(err.message, 'error')`。
- 长时间操作使用 `UI.busy(async () => { ... })`，它负责遮罩与异常提示。

## 可用全局

- `API.engine(method, params)` → Promise<any>，调用 Python 引擎 24 个 RPC 方法之一。
- `API.pickFolder(start?)`、`API.saveText(name, content)`、`API.reveal(path)`、`API.openPath(path)`。
- `API.configGet()` / `API.configSet(patch)`：应用配置（theme/lang/close_action/last_folder/scheduled）。
- `API.getAutostart()` / `API.setAutostart(bool)` / `API.scheduleSet(enabled,time,folder)` / `API.scheduleGet()`。
- `API.logList()` / `API.logRead(path)` / `API.logClear()` / `API.logLine(level,msg)`。
- `UI.h(tag, attrs, ...children)`：创建元素；attrs 支持 `class`、`text`、`html`、`onclick`、`dataset`、`style`。
- `UI.T(zh, en)`：按当前语言返回文案。
- `UI.fmtBytes(n)`、`UI.fmtCount(n)`、`UI.fmtTime(unixSec)`、`UI.fmtDateTime(isoString)`。
- `UI.toast(msg, kind)`：kind = info | ok | warn | error。
- `UI.confirm({title, body, ok, danger})` → Promise<bool>。
- `UI.busy(fn, label?)`：显示遮罩执行 fn，异常自动 toast 并返回 undefined。
- `UI.skeleton(rows)`：骨架屏节点。
- `UI.empty(text, sub?)`：空态节点。
- `UI.card(title?, ...children)`：卡片容器。
- `UI.table({columns, rows, rowKey?})`：columns = [{key,label,width,align,render(row)}]。
- `UI.icon(name, size?)`：内置 SVG 图标（organize/shots/cache/search/rules/apps/migrate/log/settings/folder/file/refresh/play/trash/undo/close/check）。
- `UI.state`：`{ lang: 'zh-CN'|'en-US', theme: 'light'|'dark' }`。
- `UI.onLangChange(fn)`：语言切换时回调（一般不需要）。
- `API.listDir(dir, limit?)`、`API.aiHttp(req)`、`API.aiStore(op, name?, content?)`：AI 助手底层（见下节）。
- `AIStore`：AI 设置与会话存储。`load(force)` / `save(patch)` / `isConfigured(s)` / `PROVIDERS` / `maskKey`；会话 `listSessions/loadSession/saveSession/deleteSession/clearAll`；`logUsage(entry)`。
- `AIChat.create(root, { ctx, compact })` → `{ask, retry, clear, loadSession, newSession, focus, setBusy}`：唯一的对话组件，整页与抽屉共用。`ctx` 是函数，返回 `{page, dir, count, size, files, note}`。
- `AIDrawer.open({title, ctx, question})` / `close()` / `isOpen()`：右侧抽屉入口。
- `AIComposer.create(host, opts)`：输入框（原版 Composer 的原生复刻）。`opts = {value, models, selectedModel, thinking, permission, disabled, busy, usage, dir, onInput, onSubmit, onStop, onModelChange, onThinkingChange, onPermissionChange}`；返回 `{el, input, value(), getValue(), setValue(v), focus(), setBusy(busy, stopping), setUsage({used,budget}), setModel(id), setThinking(k), setPermission(p), setModels(list), setDisabled(b), setReducedMotion(b), openMenu(), closeMenu(), destroy()}`。权限三档 `readonly|standard|deep` 只影响可见工具集，不含任何写工具。
- `AIEffortSlider.create(host, {stops, value, onChange, ariaLabel, disabled})` → `{el, value, setValue, setDisabled, setReducedMotion, resize, destroy}`：三档推理强度滑块（Canvas 场 + 双弹簧形变），`role=slider`，键盘 Home/End/方向键可用。
- `AIMotion`：动效内核（`spring` / `tween` / `timeline` / `springEase` / `onTick` / `prefersReduced` / `continuousRadius`）。所有动画走它的单一 ticker，页面隐藏时自动停。
- `Agent.createAgent({transport, tools, prompt, settings})`：本地环路（`run()` 返回答案、依据、建议、用量；`transport` 可注入，黄金集就是这么测的）。

## 第二轮改版：布局 / 折叠 / 右键菜单（必须遵守）

### 布局

- 页面内容由 `#scroll` 统一滚动，**页面自己不要再套 overflow:auto**，也不要写死高度。
- 页面根 `page-body` 是 `flex column`，横向用 `.grid-2` / `.grid-3` / `.row`（自动换行，窄窗自动堆叠）。
- 宽度不要写死 px；用 `minmax(0,1fr)`、`flex:1`、`gap` 撑满可用区域。**禁止大片留白**。
- 每个页面最多 3 个顶层区块；超过就折叠进 `UI.section`。

### 折叠区块

```js
UI.section(T('扫描条件','Scan options'), bodyNode, { open: true, hint: T('...','...'), id: 'opts' });
```

- `open` 默认 false，重要区块才 true；用户点击标题展开/收起。
- 高频操作放顶层（不折叠），低频参数放 section 里。

### 右键菜单（每个页面必须有）

```js
UI.attachMenu(listNode, (e) => {
  const row = e.target.closest('[data-path]');
  if (!row) return [];
  const p = row.dataset.path;
  return [
    { header: p },
    { label: T('打开所在目录','Open folder'), icon: 'folder', action: () => API.reveal(p) },
    { label: T('复制路径','Copy path'), icon: 'copy', action: () => navigator.clipboard.writeText(p) },
    { sep: true },
    { label: T('删除','Delete'), icon: 'trash', danger: true, action: async () => { ... } },
  ];
});
```

- 菜单项：`{label, icon?, danger?, disabled?, action}`、`{sep:true}`、`{header:'文本'}`。
- 全局已拦截 `contextmenu`（输入框/文本域除外），系统右键菜单不会出现。
- 空白区域也要给菜单（至少「刷新」「全选」「回到顶部」）。

### 图片预览

```js
UI.preview({ items: [{ path, name, url? }], index, title: '截图' });
```

- 自带 ←/→、Esc、滚轮缩放、+/-、定位、底部缩略点。
- `url` 不给时内部用 `convertFileSrc(path)`；加载失败回退「打开文件」。

### 文本选择

- 全局 `user-select:none`，只有 `input/textarea/[contenteditable]` 可选中；需要可复制的展示文本用 `<code class="selectable">` 或内容用 `UI.modal`（其 body 允许选中）。

### 压缩包命令（Rust 侧，不走引擎）

| 命令 | 参数 | 返回 |
|---|---|---|
| `archive_open` | `{path, password?}` | `ArchiveInfo` |
| `archive_extract` | `{path, outDir, indices?, password?, overwrite?}` | `ExtractReport` |
| `archive_create` | `{sources, dest, format, mode, password?}` | `CreateReport` |
| `archive_cancel` | `{}` | `boolean` |
| `archive_preview` | `{path, index, password?}` | `PreviewData` |
| `archive_preview_clear` | `{}` | `null` |
| `archive_rar_status` | `{}` | `{ready,path,version}` |
| `archive_rar_install` | `{}` | `{ready,path,version}` |
| `pick_archive` | `{}` | `string \| null` |
| `pick_files` | `{}` | `string[]` |
| `pick_archive_save` | `{defaultName}` | `string \| null` |

`ArchiveInfo`：`{path,format,entries:[{index,name,isDir,size,packed,modified,encrypted,crc}],totalSize,totalPacked,encrypted,solid,comment,needsRar,rarReady}`。

`ExtractReport`：`{files,dirs,bytes,skipped,warnings,outDir}`；`CreateReport`：
`{path,format,files,bytes,packed,elapsedMs}`；`PreviewData`：
`{kind,name,text,file,mime,size,truncated}`。

进度事件：`archive-progress`，payload
`{op,phase,files,totalFiles,bytes,totalBytes,name}`，前端用
`window.__TAURI__.event.listen` 订阅。

解压/保存位置由前端自建弹窗收集，`outDir` 直接传给 `archive_extract`（Rust 侧
`create_dir_all`）；`pick_archive_save` 保留但压缩包页已不再调用。
相关配置键：`archive_extract_dir`、`archive_extract_open`、`archive_create_dir`（均通过
`config_get` / `config_set` 读写）。

### 空间工具命令（Rust 侧，不走引擎）

| 命令 | 参数 | 返回 |
|---|---|---|
| `top_files` | `{dir, limit}` | `[{path,name,dir,ext,size,mtime}]`，按大小倒序，最多 500 |
| `file_signals` | `{paths:[...]}` | `{items:[{path,company,product,desc,sig,signer}]}`，一次最多 80 个，25 s 超时 |
| `scan_empty_dirs` | `{dir, max, depth?}` | `[{path,rel,depth,kind:"empty"\|"protected",why}]` |
| `remove_empty_dirs` | `{paths:[...]}` | `{removed,failed:[{path,why}]}` |

- `file_signals`：一次 PowerShell 批量读版本信息与 Authenticode 签名。`sig` 取
  `Valid / NotSigned / UnknownError / HashMismatch …`；读不到证书时按 `Present` 兜底。
  前端只用它判断「来源是否可信」，不据此自动删除。
- `scan_empty_dirs`：`depth` 默认 **3**，夹在 1–4；只把「真的没有任何条目」的目录算空目录，
  并按 `empty_dir_denied` + `empty_dir_risky` 标出 `protected`（系统目录、程序运行目录、
  `.git/.svn/.hg/.vscode/.idea/node_modules`、`config/plugins/logs/cache` 等程序常用目录、
  整理助手自己的数据目录）。`protected` 项前端不可勾选，`remove_empty_dirs` 也会再拦一次。
- `top_files` 的 `ext` 是扩展名小写，`dir` 是父目录，供前端做类型/风险标签。

### AI 助手命令（Rust 侧，不走引擎）

| 命令 | 参数 | 返回 |
|---|---|---|
| `list_dir` | `{dir, limit?}` | `{dir,total,shown,truncated,items:[{name,kind:"dir"\|"file",size,ext,mtime}]}`，目录在前 |
| `ai_http` | `{req:{url, headers?, body, timeout_ms?}}` | `{status, body, elapsed_ms}` |
| `ai_store` | `{op, name?, content?}` | `op = list \| read \| write \| append \| delete \| clear`；`list` → `{dir,items:[{name,size,mtime}]}` |

- `ai_http`：WinHTTP 直连（`windows-sys` 已有 feature，零新增依赖）。只接受 `http://` / `https://`；
  请求头里出现换行直接报「请求头包含非法字符」；响应上限 8 MB。**模型请求只从这一条命令出去**，
  不经过引擎，因此可以在前端做可取消的循环。
- `ai_store`：AI 目录是 `%LOCALAPPDATA%\整理助手数据\ai`。文件名只允许 `[A-Za-z0-9._-]` 且必须是
  `.json` / `.jsonl`；`write` 先写 `.tmp` 再改名，`clear` 只删这三类文件。
- AI 相关设置存在 `app.json` 的 `ai` 段（`endpoint` / `key` / `model` / `temperature` / `jsonMode` /
  `maxSteps` / `turnBudget` / `enabled`），由设置页「AI 助手」分组维护，密钥明文只落本机。

## 视觉规范

- 白色为主、黑色为辅，强调色只用于关键操作；不使用 emoji；图标用 `UI.icon`。
- 圆角/间距/颜色一律用 `web/styles.css` 里的 CSS 变量（`--radius-*`、`--space-*`、`--text-*`、`--bg-*`）。
- 每个交互元素要有 hover / active / focus-visible 过渡；列表整体过渡，不逐行动画。
- 文案精简，中文与英文都要写（`UI.T('中文','English')`）。

## 页面要点（与 WPF 对齐）

- **ai**：整页对话（Linear 风格：13 px 正文、查证过程默认收起、只用一种强调色）。空态给 4 个引导问题；提问后先显示「查了 N 项」可展开的过程行，再出结论；依据 chip 点开看工具原始返回；建议动作卡只有「去清理 / 复制路径」，**永远没有删除按钮**；建议追问 chip 一键续问；停止 / 重试 / 复制 / 历史（可打开与删除单条）/ 新会话。未配置模型时给引导，不假装能答。
- **organize**：加文件夹 / 加文件（可混选，来源以 chip 展示，可单个移除）、三档预设（标准 / 全部文件 / 谨慎）+ 递归、按日期、跳过最近三项开关 + 「更多选项」（识别方式、重名策略、排除扩展名/目录、快捷方式、强制）、扫描预览（分组可折叠、全选/反选/清空、跳过详情）、开始整理、撤销上次、导出 CSV、打开/定位文件、「问助手」开抽屉。
- **shots**：扫描截图目录、按大小排序、勾选、预览（大图弹层）、清理到回收站、显示释放空间。
- **cache**：缓存分组、勾选、按等级标注 safe/caution/advanced、预计释放空间、清理、结果汇总。
- **tools**：大文件排行（类型标签 / 所属软件 / 风险徽章，可用「深度分析」批量补版本信息与签名，可按类别与「需确认」筛选，只读不删）、空文件夹清理（扫描深度 1/2/3 层可选，protected 项标「不删」且不可勾选，全选可删 → 确认后删除）、「问助手」开抽屉。
- **search**：索引状态、选择索引根目录、建立/重建索引、关键词搜索、结果分页、定位文件。
- **rules**：规则文件（JSON）编辑、校验、预览、执行、执行报告。
- **apps**：已安装程序列表、搜索过滤、卸载、残留扫描、残留清理。
- **migrate**：来源可混选文件夹 / 压缩包 / 单个文件（chip 展示类型徽标）、目标目录、冲突策略（同名文件夹默认改名共存）、预演计划（含类型列）、执行、结果汇总。
- **log**：日志文件列表（Rust 侧 `app-*.log`）、内容查看、刷新、清空、打开日志目录。
- **settings**：主题、语言、关闭行为、数据目录、递归深度、冲突策略、日志保留、开机自启、定时整理、AI 助手（服务商 / 地址 / 密钥 / 模型 / 温度 / JSON 模式 / 测试连接 / 清空对话）、关于。
