FOUR CORE PILLARS · 只讲硬核重点

把最常用的四件麻烦事，做到零焦虑

01

可审计本地 AI 助手：透明查证 + 0.31ms 真停止

自带密钥直连 DeepSeek / OpenAI / Ollama 等任意兼容端点。每一步推理原文、本地工具调用与毫秒耗时全部展开可查；体积、路径自动同源核对且智能切分粘连汉字；所有写/删动作走四档权限审批卡片，点停止 0.31ms 底层断连不烧 Token。

  • 只读 / 确认 / 自动 / 放手四档可控权限
  • 双端路径防汉字粘连 + 真实磁盘存在性兜底
02

先预演再落盘的智能整理 + 一键精准撤回

扫描即预演，先看分类清单与跳过原因再执行。底层自动保护代码仓库（检测源码/配置自动拦截）、系统目录与下载中临时文件；1,000 文件 1.79 秒归位，不满意 1.39 秒原路撤回。

  • 支持自定义 YAML 规则与 AI 草稿一键导入
  • 每次整理独立留痕，随时一键还原
03

Rust 多核零广告压缩包内核

原生支持 ZIP / 7Z / RAR / TAR / TAR.GZ / BZ2 / XZ 浏览、双击内置预览、解压与打包。按本机 CPU 核数动态阶梯调速，支持分块级真暂停/秒取消、同名覆盖或并存重命名，以及单槽原子撤回。

  • 防 ZIP Slip、符号链接逃逸与 32 GiB 压缩炸弹
  • 单槽撤回机制防止大文件备份占用爆炸
04

C 盘安全清理、大文件签名溯源与事务迁移

缓存按「安全可重建 / 谨慎复核」分层标注，绝不误删聊天记录与文档；大文件直读数字签名与发行商；跨盘数据迁移带哈希校验与事务日志，按需提权、平时零特权运行。

核心自研模块

  • Rust 并发压缩内核 — 4 档动态 WorkPacer、分块暂停取消、防逃逸与单槽撤回
  • WinHTTP 真断连网关 — AI_CANCEL_EPOCH + RAII 句柄表，0.31ms 跨线程中止
  • 零新增依赖更新引擎 — installer / portable 双形态、仓库锁仓与失败自动回滚
  • 本地 AI Agent 与闸门 — Tools/JSON 自动降级、路径防粘连与四档审批提案卡
  • 事务整理引擎 + indexwalk — Dry-Run / 一键撤回 / SQLite FTS5 / Rust 高速遍历

使用的开源技术栈

  • Tauri v2 & Rust — 原生 WebView2 外壳、托盘、单实例与 IPC Channel
  • windows-sys & sha2 — WinHTTP TLS、ShellExecuteW、线程优先级与 SHA-256
  • 静态链接压缩 Crates — zip / sevenz-rust2 / lzma-rust2 / flate2(zlib-rs) / bzip2 / tar
  • Python 3.11 + SQLite FTS5 — 规则引擎、缓存分析与全文索引（单文件封装）
  • 按需官方 UnRAR64.dll — 不随包分发，首次打开 RAR 时双重 SHA-256 校验提取
